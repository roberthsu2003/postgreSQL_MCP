## 🤖 萬用提示詞

每次請 AI 寫連線程式，都附上這段：

```markdown
我的 PostgreSQL 資料庫是 cafe_shop。請先用 MCP 查看資料表結構，然後寫一個 Python 程式。

規定：
1. 用 python-dotenv 從 .env 讀取 DB_HOST、DB_PORT、DB_NAME、DB_USER、DB_PASSWORD，密碼不可寫在程式裡
2. 用 psycopg2，並用 with conn: 和 with conn.cursor() as cur: 管理交易
3. 所有使用者輸入都用 %s 參數化，不可用 f-string 組合 SQL
4. 用 try / except psycopg2.Error 處理錯誤，錯誤訊息用繁體中文
5. 加上繁體中文註解

需求：（寫上你要的功能和 SQL）
```
