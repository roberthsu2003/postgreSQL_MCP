# 英文看不懂時，先看這張對照表

本章保留英文欄位、工具與設定名稱，方便程式互相對接；**不要求背單字**。第一次看到時，先讀中文用途與例子；實際輸入名稱時才照著英文寫，大小寫和底線要一致。各單元及範例頁另附該案例的資料表／欄位表。

例如 `member_id` 是「會員編號」，`book_id` 是「書籍編號」。`borrow_book(member_id=9901, book_id=9901)` 的意思是「幫會員 9901 借書籍 9901」。兩個數字相同，但各自代表不同對象。

## 先認識會一直出現的字

| 英文原名 | 中文意思 | 在本章做什麼 |
|---|---|---|
| MCP（Model Context Protocol） | 模型上下文協定 | AI 和外部工具溝通的規格 |
| Server | 伺服器端程式 | 提供查商品、借書等功能 |
| Client | 用戶端 | 連上 Server 並呼叫工具的那一端 |
| Tool | 工具 | 一個可以呼叫的功能，例如「登記借書」 |
| Prompt | 提示詞 | 你交代 AI 需求、限制與驗收的文字 |
| parameter／argument | 參數／傳入的值 | 查哪位會員、哪一天、幾筆資料 |
| result／response | 結果／回應 | 工具查到的資料或成功／失敗訊息 |
| request | 請求 | 用戶端送出的操作要求 |
| schema | 資料綱要／結構定義，要看上下文 | `public` 是資料庫中的綱要；工具的輸入 schema 是允許哪些參數 |
| Inspector | 工具檢查器 | 不先問 AI，直接選工具、填參數來測試 |
| SDK | 軟體開發工具組 | 提供建立 MCP Server 所需的功能 |
| stdio | 標準輸入／輸出傳輸 | 個人電腦上的用戶端啟動 Server 子程序並溝通 |
| HTTP／HTTPS | 網路通訊／加密的網路通訊 | 透過網址連到遠端 Server |
| Streamable HTTP | MCP 使用的一種 HTTP 傳輸方式 | 單元 3～4 用來讓不同電腦連線 |
| Token | 通行憑證 | 本課一位使用者一組，讓 Server 辨認身分 |
| Bearer | 持有者憑證的傳送方式 | 出現在 `Authorization: Bearer ...`，後面接 Token |
| authentication | 身分驗證 | 確認你是誰、憑證是否有效 |
| authorization | 授權 | 決定你可以使用哪些工具、看哪些資料 |
| audit／log | 稽核紀錄／日誌 | 留下誰在何時呼叫什麼工具，以及錯誤資訊 |
| read-only | 唯讀 | 可以查詢，不能修改資料 |
| transaction | 交易 | 一組操作全部成功才保留；失敗就還原 |
| commit／rollback | 提交／還原 | 保留交易中的修改／取消尚未提交的修改 |

Token 有效只代表通過本課的身分驗證，不代表已做好部門授權。`instructions` 裡提醒 AI 先確認，也不能取代程式的商業檢查。

## 英文名稱怎麼拆開看？

| 常見部分 | 中文用途 | 例子 |
|---|---|---|
| `_id` | 編號，用來識別一筆資料 | `order_id`＝訂單編號，不是商品編號 |
| `name` | 名稱，要看所屬資料表 | `products.name`＝商品名稱；`members.name`＝會員姓名 |
| `date`／`_on` | 日期，前面的字說明哪一天 | `due_date`＝到期日；`joined_on`＝加入日期 |
| `search`／`find` | 搜尋／尋找 | `find_book`＝找書籍 |
| `get`／`list` | 取得／列出 | `get_store_sales`＝取得門市業績 |
| `top` | 排名前幾名 | `top_products`＝商品排行 |
| `summary`／`stats` | 彙總／統計 | `sales_summary`＝銷售彙總 |
| `keyword` | 搜尋關鍵字 | 填「拿鐵」，不是填商品編號 |
| `start_date`／`end_date` | 開始日／結束日 | `2024-01-01` 到 `2024-03-31` |
| `limit` | 最多回傳幾筆 | `limit=3`＝最多列出 3 筆，不是商品編號 3 |
| `order_by` | 排序依據 | 按銷量或營業額排，不是訂單編號 |
| `group_by` | 分組方式 | 按分類、商品或月份統計 |
| `threshold` | 門檻 | `threshold=10`＝找庫存小於等於 10 的商品 |
| `year` | 年度 | `year=2025`＝查 2025 年 |

**英文欄位與中文顯示可以同時存在。** 例如 `p.name AS 商品名稱`：`p` 是商品表的簡稱，`name` 仍是資料庫欄名，`AS 商品名稱` 只讓查詢結果顯示中文標題，沒有把原欄位改名。

## 設定檔中的英文

| 原名 | 中文意思 | 你需要知道什麼 |
|---|---|---|
| `mcpServers` | MCP 伺服器清單 | 放每一個 Server 的連線設定 |
| `command`／`args` | 啟動程式／附加參數 | 本機模式用來告訴用戶端怎麼啟動 Server |
| `env` | 環境變數設定 | 提供本次啟動所需的連線資料 |
| `DATABASE_URI` | 資料庫連線字串 | 包含帳號、主機、埠與資料庫；不能只填資料庫名稱 |
| `serverUrl`／`url` | 伺服器網址 | 遠端 MCP 的連線位置，不是資料庫網址 |
| `headers` | HTTP 標頭 | 連線時附帶的資訊，例如身分憑證 |
| `Authorization` | 身分憑證標頭名稱 | 這裡放 `Bearer` 加上個人 Token |
| `AUTH_HEADER` | 本例用來保存身分標頭內容的環境變數 | 值是 `Bearer 個人Token`，不是資料庫密碼 |
| `MCP_HOST`／`MCP_PORT` | MCP 監聽主機／埠號 | 決定 Server 在哪個介面、哪個埠接收連線 |
| `MCP_TRANSPORT` | MCP 傳輸模式 | 範例集使用 `stdio` 或 `http` |
| `POSTGRES_PASSWORD` | PostgreSQL 容器初始化使用的管理員密碼設定 | 不是員工Token；修改此設定不等於修改既有資料庫的密碼 |
| `PYTHONUNBUFFERED` | 讓Python即時輸出日誌 | 避免紀錄暫存太久才出現在容器日誌 |
| `MCP_USER` | 本機稽核顯示的使用者名稱 | 不是資料庫登入帳號，也不等於已做身分驗證 |
| `localhost`／`127.0.0.1` | 程式所在位置的本機 | 搬到容器後就代表那個容器，不再是你的電腦 |
| `0.0.0.0` | 監聽所有網路介面 | 給伺服器監聽用，員工連線改填實際 IP／網域 |
| uv／pip | Python 環境與套件管理工具 | 由 AI 依本單元套件清單準備環境 |
| Node.js／npx | JavaScript 執行環境／套件執行工具 | Inspector 與 mcp-remote 轉接工具會用到 |
| SSH／scp | 遠端登入／傳送檔案 | 登入樹莓派操作／把本機檔案傳到樹莓派 |
| `requirements.txt` | Python 套件清單 | 交給 AI 準備依賴，不用自己猜要安裝什麼 |
| `tokens.example.json` | Token 設定範本 | example＝範例，裡面的假 Token 不能當真實憑證 |

## 選讀程式碼時會遇到的字

| 原名 | 中文意思與作用 |
|---|---|
| `import`／`from` | 載入別的套件或模組提供的功能 |
| `def` | 定義一個功能；後面接功能名稱 |
| `str`／`int`／`bool`／`date` | 文字／整數／真假值／日期；告訴工具參數接受什麼 |
| `True`／`False`／`None` | Python 的真／假／沒有值；JSON 中對應 true／false／null |
| `list[dict]` | 多筆資料，每筆包含欄名和值，例如一份商品清單 |
| `instructions` | 給 AI 的角色與使用規則說明 |
| `docstring` | 功能下方的說明文字，讓 AI 知道工具用途 |
| `Literal` | 只接受列出的選項，例如只允許「銷量」或「營業額」 |
| `ToolAnnotations`／`annotations` | 工具的特性標註，提醒用戶端這個工具會做什麼 |
| `read_only_hint` | 是否唯讀的提示；hint＝提示，不能取代資料庫權限 |
| `destructive_hint` | 是否可能造成破壞性修改的提示 |
| `idempotent_hint` | 重複呼叫是否維持相同效果的提示 |
| `query`／`params` | 查詢功能／傳入的參數值 |
| `%s` | psycopg2 的值參數位置；值另外傳入，不能把它換成自己拼接的輸入 |
| `with`／`try`／`finally` | 執行區塊／嘗試操作／最後一定執行的清理區塊；具體交易與關閉連線仍看程式寫法 |
| `FOR UPDATE` | 鎖定查到的資料列，讓同時修改同一對象的操作依序處理 |
| `stderr`／`stdout` | 錯誤與日誌輸出／一般輸出；stdio 模式把 stdout 留給 MCP 協定使用 |

## 部署與常見訊息

| 英文 | 中文意思 | 下一步 |
|---|---|---|
| Docker image／container | 映像檔／容器 | 映像檔像打包好的程式，容器是正在執行的實例 |
| Docker Compose | 多容器管理工具 | 一份設定描述 MCP、資料庫、網路與資料卷 |
| `build`／`restart` | 建立映像檔／重新啟動 | 程式變更需重新打包；本課 Token 變更後需重啟 MCP |
| `volume`／`network` | 資料卷／網路 | 保存資料或掛載檔案／讓服務彼此連線 |
| `Up`／healthy | 容器運行中／通過健康檢查 | 仍需實際呼叫工具查庫，不等於全部驗收完成 |
| `Connect`／`List Tools`／`Run Tool` | 連線／列出工具／執行工具 | Inspector 的三個常用操作 |
| `HTTP 200 OK` | HTTP 請求成功 | 還要檢查工具是否執行成功及資料是否正確 |
| `HTTP 401 Unauthorized` | 未通過身分驗證 | 檢查 Token、Bearer 格式與是否已重啟載入清單 |
| `Connection refused` | 連線遭拒絕 | 檢查 Server 是否啟動、主機與埠是否正確 |
| `Input should be ...`／`ValidationError` | 輸入應符合指定選項／參數格式錯誤 | 對照工具允許的選項、日期與數值範圍 |
| `ModuleNotFoundError` | 找不到套件或模組 | 請 AI 檢查是否使用本單元的環境與依賴 |
| `KeyError: DATABASE_URI` | 缺少資料庫連線設定 | 先設定環境變數，再重新啟動 |
| `relation ... does not exist` | 找不到資料表 | 檢查目前資料庫、綱要與是否已匯入對應 SQL |
| `permission denied`／`read-only transaction` | 權限不足／唯讀交易不能寫入 | 查詢與寫入連線分開檢查，不能直接改用最高權限掩蓋問題 |

## 看不懂英文時，貼給 AI

```text
我的英文不熟，請全程用繁體中文解釋。
保留英文欄位、工具與設定的原名，但第一次出現時附上中文用途和一個本課例子。
請告訴我這個字是「資料表、欄位、工具、參數、設定」還是「錯誤訊息」。
例如 member_id 要說成「會員編號 member_id」，不要只重複英文。
不要為了翻譯而修改程式欄名，也不要把姓名和編號混為一談。
請解釋我貼的這一段，最後告訴我應該輸入什麼、在哪裡操作、完成後看到什麼：
（貼上看不懂的文字或訊息，先遮掉密碼與Token）
```
