## 問題 4：「各門市有哪些員工？薪水多少？」

員工表只有門市編號，要接上門市表才有店名：

```sql
SELECT s.name AS 門市, e.name AS 員工, e.title AS 職稱, e.salary AS 月薪
FROM staff e
JOIN stores s ON e.store_id = s.store_id
ORDER BY s.store_id, e.salary DESC;
```

**執行結果**

| 門市 | 員工 | 職稱 | 月薪 |
|---|---|---|---:|
| 台北信義店 | 張志明 | 店長 | 52000 |
| 台北信義店 | 陳美玲 | 正職咖啡師 | 38000 |

## 問題 5：「茶飲類有哪些商品？」

```sql
SELECT p.name AS 商品, p.price AS 售價
FROM products p
JOIN categories c ON p.category_id = c.category_id
WHERE c.name = '特調茶飲'
ORDER BY p.price;
```

**執行結果**

| 商品 | 售價 |
|---|---:|
| 蜜香紅茶 | 50 |
| 翡翠檸檬綠 | 60 |
| 珍珠醇奶茶 | 65 |
| 紅玉白桃烏龍 | 75 |
| 靜岡抹茶歐蕾 | 110 |

## 下手的三個步驟

遇到任何問題，都這樣拆解：

| 步驟 | 問自己 | 問題 5 的答案 |
|---|---|---|
| 1. 要看什麼？ | `SELECT` 哪些欄位 | 商品名稱、售價 |
| 2. 資料在哪？ | `FROM`、`JOIN` 哪些表 | `products`、`categories` |
| 3. 什麼條件？ | `WHERE`、`ORDER BY` | 分類是特調茶飲，依價格排序 |

## ⚠️ 常見卡關

| 問題 | 原因 | 怎麼解 |
|---|---|---|
| `column "city" does not exist` | 這個資料庫的欄位叫 `region` | 先看資料表結構，不要憑感覺猜 |
| 不知道有哪些值可以篩 | 沒看過資料 | `SELECT DISTINCT 欄位 FROM 表` 先看 |
| 查無資料 | 文字要完全相符 | 查正確值再寫條件 |

## ✍️ 動手練

**第 1 題**：列出「北部」門市所有的店長姓名和門市名稱。

<details>
<summary>看答案</summary>

```sql
SELECT e.name AS 店長, s.name AS 門市
FROM staff e
JOIN stores s ON e.store_id = s.store_id
WHERE s.region = '北部' AND e.title = '店長';
```

| 店長 | 門市 |
|---|---|
| 張志明 | 台北信義店 |
| 黃雅婷 | 台北車站店 |

**第 2 題**：2024 年 2 月之後才上市的商品有哪些？屬於什麼分類？

<details>
<summary>看答案</summary>

```sql
SELECT p.name AS 商品, c.name AS 分類, p.launched_on AS 上市日
FROM products p
JOIN categories c ON p.category_id = c.category_id
WHERE p.launched_on >= '2024-02-01'
ORDER BY p.launched_on;
```

**執行結果**

| 商品 | 分類 | 上市日 |

| 紅玉白桃烏龍 | 特調茶飲 | 2024-02-01 |
| 草莓生乳千層 | 現烤點心 | 2024-02-05 |
| 冰滴咖啡 | 義式咖啡 | 2024-03-01 |

</details>

**第 3 題**：列出 2024-01-01 那天的訂單，顯示訂單編號、門市和經手員工。

<details>
<summary>看答案</summary>

```sql
SELECT o.order_id AS 訂單, s.name AS 門市, e.name AS 經手員工
FROM orders o
JOIN stores s ON o.store_id = s.store_id
JOIN staff e  ON o.staff_id = e.staff_id
WHERE o.order_date = '2024-01-01'
ORDER BY o.order_id;
```
