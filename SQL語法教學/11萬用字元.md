# 進階-5｜模糊搜尋：只記得一部分也找得到

> ⏱️ **15 分鐘** ｜ 💻 DBeaver（資料庫：`cafe_shop`）｜ 📄 練習腳本：[`11萬用字元.sql`](./11萬用字元.sql) ｜ 🎯 學完你會：`LIKE`、`ILIKE`、`%`、`_`

## 🎬 情境

客人來電：「我上次買那個什麼拿鐵……」你只記得兩個字。

就像 Excel 篩選裡的「包含」，SQL 用 `LIKE` 搜尋部分文字。

## 兩個萬用字元

| 符號 | 意思 | 例子 | 比對得到 | 比對不到 |
|:---:|---|---|---|---|
| `%` | 任意長度（也可以是 0 個字） | `'%拿鐵'` | 經典拿鐵、燕麥奶拿鐵 | 拿鐵咖啡 |
| `_` | 剛好 1 個字 | `'陳__'` | 陳冠宇 | 陳一、陳小小華 |

## 1. 三種最常用的寫法

**包含**（字在哪裡都行）：

```sql
SELECT name, price
FROM products
WHERE name LIKE '%拿鐵%';
```

**執行結果**

| name | price |
|---|---:|
| 經典拿鐵 | 95 |
| 燕麥奶拿鐵 | 130 |

**開頭是**：

```sql
SELECT name, address
FROM stores
WHERE address LIKE '台北市%';
```

**執行結果**

| name | address |
|---|---|
| 台北信義店 | 台北市信義區忠孝東路五段 |
| 台北車站店 | 台北市中正區忠孝西路一段 |

**結尾是**：

```sql
SELECT name FROM products WHERE name LIKE '%咖啡';
```

**執行結果**

| name |
|---|
| 美式咖啡 |
| 摩卡咖啡 |
| 冰滴咖啡 |

## 2. % 的位置有差

```sql
SELECT COUNT(*) AS 開頭是拿鐵 FROM products WHERE name LIKE '拿鐵%';
```

**執行結果**

| 開頭是拿鐵 |
|---:|
| 0 |

資料庫裡的品名是「經典拿鐵」，所以「開頭是拿鐵」查不到。查無資料時，先想想 `%` 放對了沒。

## 3. 底線：指定字數

姓陳、剛好三個字的會員：

```sql
SELECT DISTINCT name
FROM customers
WHERE name LIKE '陳__';
```

**執行結果**

| name |
|---|
| 陳冠宇 |

## 4. ILIKE：不分大小寫

`LIKE` 分大小寫。查英文時用 PostgreSQL 特有的 `ILIKE`：

```sql
SELECT DISTINCT payment_method, 'LIKE' AS 方法 FROM orders WHERE payment_method LIKE 'line%'
UNION ALL
SELECT DISTINCT payment_method, 'ILIKE' FROM orders WHERE payment_method ILIKE 'line%';
```

**執行結果**

| payment_method | 方法 |
|---|---|
| LINE Pay | ILIKE |

只有 `ILIKE` 找得到 `LINE Pay`。

## ⚠️ 常見卡關

| 問題 | 原因 | 怎麼解 |
|---|---|---|
| 查不到 | 忘了加 `%` | `LIKE '拿鐵'` 等於完全相符，改成 `'%拿鐵%'` |
| 查不到英文 | 大小寫不同 | 改用 `ILIKE` |
| 資料多時很慢 | `%` 開頭無法用一般索引 | 能用開頭比對就用開頭比對 |
| 要查 `%` 這個字本身 | 它被當萬用字元 | 寫成 `'%50\%%'`，用 `\` 跳脫 |
