# DML-2｜查詢資料：SELECT，你最常用的指令

> ⏱️ **45 分鐘** ｜ 💻 DBeaver（資料庫：`cafe_shop`）｜ 🎯 學完你會：挑欄位、篩條件、排序、取前幾名

## 🎬 情境

王經理的 LINE 整天響個不停：

> 「高單價商品有哪些？」「最貴的前三名？」「第一季有多少筆沒有會員的訂單？」

這些問題在 Excel 要篩選、排序、複製貼上。學會 `SELECT`，一句話就答完。

**先切換到 `cafe_shop`** 再開始。

## SELECT 的骨架

```sql
SELECT 要哪些欄位      -- 相當於 Excel 隱藏不要的欄
FROM 哪張表            -- 哪個工作表
WHERE 條件             -- 篩選
ORDER BY 排序依據       -- 排序
LIMIT 幾筆;            -- 只要前幾筆
```

順序不能調換，但只有 `SELECT` 和 `FROM` 是必要的。

## 1. 挑欄位

```sql
SELECT name, region, phone
FROM stores;
```

**執行結果**

| name | region | phone |
|---|---|---|
| 台北信義店 | 北部 | 02-2720-1111 |
| 台北車站店 | 北部 | 02-2311-2222 |
| 新竹巨城店 | 北部 | 03-535-3333 |
| 台中逢甲店 | 中部 | 04-2451-4444 |
| 高雄巨蛋店 | 南部 | 07-555-5555 |

`SELECT *` 代表全部欄位。探索資料時很好用，正式程式裡最好寫清楚要哪幾欄。

### 用 AS 取中文名稱，報表更好讀

```sql
SELECT name AS 門市, region AS 區域
FROM stores;
```

**執行結果**

| 門市 | 區域 |
|---|---|
| 台北信義店 | 北部 |
| 台北車站店 | 北部 |

<sub>（只列前 2 筆，實際共 5 筆）</sub>

### 直接算出新欄位

每項商品賺多少？

```sql
SELECT name AS 商品, price AS 售價, cost AS 成本, price - cost AS 毛利
FROM products;
```

**執行結果**

| 商品 | 售價 | 成本 | 毛利 |
|---|---:|---:|---:|
| 美式咖啡 | 70 | 20 | 50 |
| 經典拿鐵 | 95 | 35 | 60 |
| 焦糖瑪奇朵 | 120 | 45 | 75 |

<sub>（只列前 3 筆，實際共 18 筆）</sub>

### 去掉重複：DISTINCT

門市分布在哪些區域？

```sql
SELECT DISTINCT region FROM stores;
```

**執行結果**

| region |
|---|
| 北部 |
| 中部 |
| 南部 |

## 2. 篩條件：WHERE

**「高單價商品有哪些？」**（售價超過 120 元）

```sql
SELECT name, price
FROM products
WHERE price > 120;
```

**執行結果**

| name | price |
|---|---:|
| 燕麥奶拿鐵 | 130 |
| 冰滴咖啡 | 150 |
| 草莓生乳千層 | 140 |

常用的比較符號：

| 符號 | 意思 | 例子 |
|---|---|---|
| `=` | 等於 | `region = '北部'` |
| `<>` 或 `!=` | 不等於 | `status <> '已完成'` |
| `>` `<` `>=` `<=` | 大小比較 | `price >= 100` |
| `BETWEEN a AND b` | 介於（含頭尾） | `price BETWEEN 100 AND 150` |
| `IN (...)` | 符合清單中任一個 | `category_id IN (1, 2)` |
| `LIKE` | 模糊比對 | `name LIKE '%拿鐵%'` |
| `IS NULL` | 是空值 | `customer_id IS NULL` |

### AND、OR：組合條件

```sql
-- AND：兩個條件都要符合。2024 年 3 月用信用卡的已完成訂單有幾筆？
SELECT COUNT(*) AS 筆數
FROM orders
WHERE order_date BETWEEN '2024-03-01' AND '2024-03-31'
  AND payment_method = '信用卡'
  AND status = '已完成';
```

**執行結果**

| 筆數 |
|---:|
| 33 |

`COUNT(*)` 是「數有幾筆」，[進階-4](./10聚合函式.md) 會細講。

```sql
-- OR：符合其中一個就算。電子支付的訂單前 3 筆
SELECT order_id, payment_method
FROM orders
WHERE payment_method = 'LINE Pay' OR payment_method = '街口支付'
ORDER BY order_id
LIMIT 3;
```

**執行結果**

| order_id | payment_method |
|---:|---|
| 2 | LINE Pay |
| 6 | 街口支付 |
| 7 | 街口支付 |

上面的 `OR` 也能寫成 `payment_method IN ('LINE Pay', '街口支付')`，更簡潔。

> [!WARNING]
> **`AND` 和 `OR` 混用時要加括號**。`AND` 會先算，所以 `a OR b AND c` 的意思是 `a OR (b AND c)`。不確定時就加括號。

### 找出空值：要用 IS NULL

「有多少筆訂單沒有會員？」（`customer_id` 空白代表散客）

```sql
SELECT COUNT(*) AS 散客訂單數
FROM orders
WHERE customer_id IS NULL;
```

**執行結果**

| 散客訂單數 |
|---:|
| 154 |

> [!CAUTION]
> 寫成 `customer_id = NULL` **不會報錯，但永遠查不到資料**。試試看：

```sql
SELECT COUNT(*) AS 錯誤寫法的結果
FROM orders
WHERE customer_id = NULL;
```

**執行結果**

| 錯誤寫法的結果 |
|---:|
| 0 |

## 3. 排序：ORDER BY

`ASC` 是由小到大（預設），`DESC` 是由大到小。

```sql
-- 先依區域，同區域再依門市名稱
SELECT region, name
FROM stores
ORDER BY region, name;
```

**執行結果**

| region | name |
|---|---|
| 中部 | 台中逢甲店 |
| 北部 | 台北信義店 |
| 北部 | 台北車站店 |
| 北部 | 新竹巨城店 |
| 南部 | 高雄巨蛋店 |

## 4. 取前幾名：LIMIT

**「最貴的前三名？」**

```sql
SELECT name, price
FROM products
ORDER BY price DESC
LIMIT 3;
```

**執行結果**

| name | price |
|---|---:|
| 冰滴咖啡 | 150 |
| 草莓生乳千層 | 140 |
| 燕麥奶拿鐵 | 130 |

> [!TIP]
> 想取前幾名，一定要搭配 `ORDER BY`。沒有排序的話，資料庫不保證回傳順序。

### 分頁：OFFSET

App 表格常用：每頁 5 筆，第 2 頁就是跳過前 5 筆。

```sql
SELECT product_id, name
FROM products
ORDER BY product_id
LIMIT 5 OFFSET 5;
```

**執行結果**

| product_id | name |
|---:|---|
| 6 | 冰滴咖啡 |
| 7 | 蜜香紅茶 |
| 8 | 翡翠檸檬綠 |
| 9 | 珍珠醇奶茶 |
| 10 | 靜岡抹茶歐蕾 |

## ⚠️ 常見卡關

| 問題 | 原因 | 怎麼解 |
|---|---|---|
| `column "北部" does not exist` | 文字用了雙引號 | 改單引號 |
| `column "city" does not exist` | 欄位名稱打錯 | 雙擊資料表，看 Properties |
| `syntax error at or near "WHERE"` | 子句順序錯了 | 照 SELECT → FROM → WHERE → ORDER BY → LIMIT |
| 查不到資料也沒報錯 | 條件寫錯，或用了 `= NULL` | 先拿掉 WHERE，看資料長怎樣 |
| `LIKE` 找不到 | 少了 `%` | `'%拿鐵%'` 才是「包含」 |

| 郭俊宏 | 53000 |
| 張志明 | 52000 |

**第 2 題**：毛利（`price - cost`）大於 80 元的商品，依毛利由高到低列出。

<details>
<summary>看答案</summary>

```sql
SELECT name, price - cost AS 毛利
FROM products
WHERE price - cost > 80
ORDER BY 毛利 DESC;
```

**執行結果**

| name | 毛利 |
|---|---:|
| 冰滴咖啡 | 90 |
| 草莓生乳千層 | 85 |

注意：`WHERE` 裡要寫完整的 `price - cost`，不能用別名 `毛利`，但 `ORDER BY` 可以。

</details>
