# 單元 8：查詢資料 (SELECT, WHERE, ORDER BY, LIMIT)

`SELECT` 是整個 SQL 中最常用、最核心的指令。  
本單元以連鎖咖啡門市的**「商品資料表 (`products`)」**與**「門市資料表 (`stores`)」**為例，學習如何精準抓取所需的商業資料！

---

## 1. 基礎查詢與欄位選擇

```sql
-- 1. 查詢門市表的所有欄位
SELECT * FROM stores;

-- 2. 僅選取業務需要的特定欄位 (節省網路傳輸與記憶體)
SELECT name, city, phone 
FROM stores;

-- 3. 使用別名 (AS) 讓報表更親切好讀
SELECT 
    name AS 門市名稱, 
    city AS 所在城市, 
    phone AS 門市電話
FROM stores;

-- 4. 去除重複值 (DISTINCT) 找出品牌門市涵蓋的所有城市
SELECT DISTINCT city 
FROM stores;
```

---

## 2. 條件過濾 (WHERE)

使用 `WHERE` 子句篩選符合特定條件的資料列：

### (1) 比較運算子 (`=`, `!=`, `>`, `<`, `>=`, `<=`)
```sql
-- 找出單價大於 100 元的中高階飲品
SELECT name, price 
FROM products 
WHERE price > 100;

-- 找出不在台北市的所有分店
SELECT name, city 
FROM stores 
WHERE city != '台北市';
```

### (2) 邏輯運算子 (`AND`, `OR`, `NOT`)
```sql
-- 找出「台北市」且「屬於特約店」的門市
SELECT * FROM stores 
WHERE city = '台北市' AND name LIKE '%旗艦%';

-- 找出價格在 100 到 150 之間的咖啡 (使用 BETWEEN)
SELECT name, price 
FROM products 
WHERE price BETWEEN 100 AND 150;
```

### (3) 清單包含 (`IN`) 與 空值判斷 (`IS NULL`)
```sql
-- 找出特定分類代碼的商品 (分類 1, 2, 4)
SELECT name, category_id, price 
FROM products 
WHERE category_id IN (1, 2, 4);

-- 找出尚未填寫電話的門市
SELECT name, city 
FROM stores 
WHERE phone IS NULL;
```

---

## 3. 資料排序 (ORDER BY)

```sql
-- 1. 依商品價格由低到高排序 (ASC，預設)
SELECT name, price 
FROM products 
ORDER BY price ASC;

-- 2. 依商品價格由高到低排序 (DESC)
SELECT name, price 
FROM products 
ORDER BY price DESC;

-- 3. 多重排序：先按城市排序，同城市的門市再按店名排序
SELECT city, name, phone 
FROM stores 
ORDER BY city ASC, name ASC;
```

---

## 4. 限制筆數與分頁 (LIMIT & OFFSET)

在設計個人桌面 App 的表格視圖時，一次載入幾萬筆容易卡頓，通常需要分頁：

```sql
-- 取出價格最高的前 5 名明星商品 (TOP 5)
SELECT name, price 
FROM products 
ORDER BY price DESC 
LIMIT 5;

-- 分頁查詢：第 2 頁 (跳過前 5 筆，取接下來的 5 筆)
SELECT name, price 
FROM products 
ORDER BY product_id ASC 
LIMIT 5 OFFSET 5;
```
