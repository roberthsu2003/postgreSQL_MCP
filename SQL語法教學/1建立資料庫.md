# 單元 1：建立與管理資料庫

在進入資料表設計之前，第一步是為你的專案建立一個獨立的資料庫空間（Database）。  
在本課程中，我們將以打造**連鎖咖啡門市營運系統 (`cafe_db`)** 為貫穿實戰範例！

---

## 1. 建立資料庫 (CREATE DATABASE)

### 標準 SQL 語法

```sql
CREATE DATABASE cafe_db;
```

> [!NOTE] 大小寫規範
> 在 PostgreSQL 中，若識別名稱（資料庫名、資料表名、欄位名）沒有加上英文雙引號，系統會**自動轉為全小寫**存儲。因此即使輸入 `CREATE DATABASE CAFE_DB;`，實際建立的資料庫名稱仍為 `cafe_db`。

---

## 2. 查詢資料庫清單

### 方法 A：在 DBeaver 圖形工具中檢視
在 DBeaver 左側連線導覽列中，展開你的連線節點 ➡️ **Databases**，即可看到目前所有的資料庫清單。

### 方法 B：使用標準 SQL 查詢
```sql
SELECT datname AS 資料庫名稱 
FROM pg_database 
WHERE datistemplate = false;
```

### 方法 C：使用 psql 命令列指令
```bash
\l
```

---

## 3. 刪除資料庫 (DROP DATABASE)

> [!CAUTION] 危險操作提醒
> 刪除資料庫會**永久抹除該資料庫內的所有資料表、結構與資料**，且無法復原！在正式環境中必須極度謹慎。

```sql
DROP DATABASE IF EXISTS cafe_db;
```
