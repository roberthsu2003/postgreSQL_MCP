# DML-1｜新增資料：INSERT

> 💻 DBeaver（資料庫：`cafe_db`）｜ 🎯 學完你會：新增單筆與多筆資料，並拿回自動產生的編號

## 🎬 情境

王經理：「這五家門市先登記進去。」

先確認你在 `cafe_db`，而且 [DDL-3](./2建立資料表.md) 的 `stores` 表還在。

## 1. 新增一筆

```sql
INSERT INTO 資料表 (欄位1, 欄位2)
VALUES (值1, 值2);
```

```sql
INSERT INTO stores (name, address, region, phone)
VALUES ('台北信義店', '台北市信義區忠孝東路五段', '北部', '02-2720-1111');
```

欄位和值要**一對一按順序**對上。`store_id` 沒有填，因為 `SERIAL` 會自動編號。

> [!IMPORTANT]
> 文字和日期要用**單引號** `'`，數字不用。寫成雙引號 `"` 會被當成欄位名稱，是新手最常遇到的錯誤。

```sql
INSERT INTO stores (name, address, region)
VALUES ("台北車站店", "台北市中正區", "北部");
```

> 🛑 **資料庫回應**：`column "台北車站店" does not exist`

看到 `column ... does not exist`，先檢查是不是用錯引號。

## 2. 一次新增多筆

用逗號分開每一組值，比一句一句寫快得多：

```sql
INSERT INTO stores (name, address, region, phone)
VALUES
    ('台北車站店', '台北市中正區忠孝西路一段', '北部', '02-2311-2222'),
    ('新竹巨城店', '新竹市東區中央路',         '北部', '03-535-3333'),
    ('台中逢甲店', '台中市西屯區逢甲路',       '中部', '04-2451-4444');
```

## 3. 有些欄位可以不填

`phone` 沒有 `NOT NULL`，不寫就會存成空值（`NULL`）：

```sql
INSERT INTO stores (name, address, region)
VALUES ('高雄巨蛋店', '高雄市左營區博愛二路', '南部');

SELECT store_id, name, region, phone FROM stores ORDER BY store_id;
```

**執行結果**

| store_id | name | region | phone |
|---:|---|---|---|
| 1 | 台北信義店 | 北部 | 02-2720-1111 |
| 2 | 台北車站店 | 北部 | 02-2311-2222 |
| 3 | 新竹巨城店 | 北部 | 03-535-3333 |
| 4 | 台中逢甲店 | 中部 | 04-2451-4444 |
| 5 | 高雄巨蛋店 | 南部 | *NULL* |

`NULL` 的意思是「沒有資料」，它不等於 0，也不等於空字串。

## 4. 拿回自動產生的編號：RETURNING

之後寫 App 很常需要「新增訂單後，馬上拿到訂單編號來新增明細」。加上 `RETURNING` 就行，不用再查一次：

```sql
INSERT INTO stores (name, address, region, phone)
VALUES ('台南西門店', '台南市中西區西門路一段', '南部', '06-213-0005')
RETURNING store_id, name;
```

**執行結果**

| store_id | name |
|---:|---|
| 6 | 台南西門店 |

## 5. 編號重複會被擋

```sql
INSERT INTO stores (store_id, name, address, region)
VALUES (1, '重複門市', '台北市', '北部');
```

> 🛑 **資料庫回應**：`duplicate key value violates unique constraint "stores_pkey"`

主鍵不能重複。平常不要自己指定 `store_id`，讓資料庫自動編號最安全。

## ⚠️ 常見卡關

| 錯誤訊息 | 原因 | 怎麼解 |
|---|---|---|
| `column "台北車站店" does not exist` | 文字用了雙引號 | 改成單引號 |
| `INSERT has more target columns than expressions` | 欄位比值多 | 數一數，讓兩邊數量相同 |
| `null value in column "address" ... violates not-null` | 漏填必填欄 | 補上該欄位 |
| `duplicate key value` | 主鍵或 UNIQUE 欄位重複 | 換值，或不要手動指定編號 |
| `relation "stores" does not exist` | 表不在目前的資料庫 | 檢查工具列是不是 `cafe_db` |
