# 進階-6｜聯集：把兩份名單上下疊起來

> 💻 DBeaver（資料庫：`cafe_shop`）｜ 📄 練習腳本：[`12聯集.sql`](./12聯集.sql) ｜ 🎯 學完你會：`UNION`、`UNION ALL`，並分辨它和 JOIN 的差別

## 🎬 情境

週年慶要寄簡訊，王經理要一份名單：所有門市和所有會員的電話放在一起。

資料在兩張表，欄位意義相同。這就像在 Excel 把第二份名單**貼到第一份的下面**。

| | 方向 | 比喻 |
|---|---|---|
| `JOIN` | 左右接，欄位變多 | VLOOKUP |
| `UNION` | **上下疊，列數變多** | 複製貼到下面 |

## 1. 基本用法

```sql
SELECT name AS 名稱, phone AS 電話, '門市' AS 類別
FROM stores
UNION ALL
SELECT name, phone, '會員'
FROM customers
ORDER BY 類別 DESC, 名稱
LIMIT 7;
```

**執行結果**

| 名稱 | 電話 | 類別 |
|---|---|---|
| 台中逢甲店 | 04-2451-4444 | 門市 |
| 台北信義店 | 02-2720-1111 | 門市 |
| 台北車站店 | 02-2311-2222 | 門市 |
| 新竹巨城店 | 03-535-3333 | 門市 |
| 高雄巨蛋店 | 07-555-5555 | 門市 |
| 劉欣宜 | 0936-805-870 | 會員 |
| 劉欣宜 | 0973-709-956 | 會員 |

**重點：**
- 欄位名稱以第一個 `SELECT` 為準
- 可以直接寫 `'門市'` 這種固定文字，標出來源
- `ORDER BY` 放在最後，會排序全部結果

## 2. UNION 和 UNION ALL

| | 重複的列 | 速度 | 何時用 |
|---|---|---|---|
| `UNION` | 自動去除 | 較慢 | 要不重複的名單 |
| `UNION ALL` | 全部保留 | 快 | 預設用它，資料不會少 |

直接比較，把門市區域清單疊兩次：

```sql
SELECT 'UNION' AS 寫法, COUNT(*) AS 筆數
FROM (
    SELECT region FROM stores
    UNION
    SELECT region FROM stores
) AS a
UNION ALL
SELECT 'UNION ALL', COUNT(*)
FROM (
    SELECT region FROM stores
    UNION ALL
    SELECT region FROM stores
) AS b;
```

**執行結果**

| 寫法 | 筆數 |
|---|---:|
| UNION | 3 |
| UNION ALL | 10 |

## 3. 兩條規則

**規則 1：欄位數量要相同**

```sql
SELECT name, phone FROM stores
UNION
SELECT name FROM customers;
```

> 🛑 **資料庫回應**：`each UNION query must have the same number of columns`

**規則 2：對應欄位的型別要相容**

```sql
SELECT name FROM stores
UNION
SELECT customer_id FROM customers;
```

> 🛑 **資料庫回應**：`UNION types character varying and integer cannot be matched`

## 4. 實用例子：業績總表加合計列

```sql
SELECT s.name AS 門市, SUM(i.quantity * i.unit_price) AS 營業額
FROM orders o
JOIN stores s ON o.store_id = s.store_id
JOIN order_items i ON o.order_id = i.order_id
WHERE o.status = '已完成'
GROUP BY s.name
UNION ALL
SELECT '★ 合計', SUM(i.quantity * i.unit_price)
FROM orders o
JOIN order_items i ON o.order_id = i.order_id
WHERE o.status = '已完成'
ORDER BY 營業額;
```

**執行結果**

| 門市 | 營業額 |
|---|---:|
| 台北車站店 | 14215 |
| 新竹巨城店 | 15365 |
| 台北信義店 | 16170 |
| 高雄巨蛋店 | 16440 |
| 台中逢甲店 | 18795 |
| ★ 合計 | 80985 |

## ⚠️ 常見卡關

| 錯誤訊息 | 原因 | 怎麼解 |
|---|---|---|
| `each UNION query must have the same number of columns` | 欄位數不同 | 補齊，沒有的欄位可放 `NULL` |
| `UNION types ... cannot be matched` | 型別不相容 | 用 `::TEXT` 統一型別 |
| `ORDER BY` 報錯 | 不能用第二段的欄位名 | 用第一段的欄位名或別名 |

## ✍️ 動手練

**第 1 題**：做一份全體人員名單，列出姓名和身分（員工或會員）。依身分排序，取前 3 筆。

<details>
<summary>看答案</summary>

```sql
SELECT name AS 姓名, '員工' AS 身分 FROM staff
UNION ALL
SELECT name, '會員' FROM customers
ORDER BY 身分 DESC, 姓名
LIMIT 3;
```

**執行結果**

| 姓名 | 身分 |
|---|---|
| 劉欣宜 | 會員 |
| 劉欣宜 | 會員 |
| 劉欣宜 | 會員 |

</details>

**第 2 題**：員工沒有電話欄位，要怎麼把員工和會員放進同一份有電話欄的名單？

<details>
<summary>看答案</summary>

用 `NULL` 補位：

```sql
SELECT name, NULL AS phone, '員工' AS 身分 FROM staff
UNION ALL
SELECT name, phone, '會員' FROM customers
LIMIT 2;
```

**執行結果**

| name | phone | 身分 |
|---|---:|---|
| 張志明 | *NULL* | 員工 |
| 陳美玲 | *NULL* | 員工 |

</details>
