## 取得資料

### 語法

```sql
SELECT 
  select_list 
FROM 
  table_name 
WHERE 
  condition 
ORDER BY 
  sort_expression;
```

### WHERE 常用的運算子

| 類型 | 運算子 |
|---|---|
| 比較 | `=`、`>`、`<`、`>=`、`<=`、`<>` 或 `!=` |
| 邏輯 | `AND`、`OR`、`NOT` |
| 範圍與清單 | `BETWEEN … AND …`、`IN (…)` |
| 文字比對 | `LIKE`（`%` 代表任意多個字元，`_` 代表一個字元） |
| 空值 | `IS NULL`、`IS NOT NULL`（不能用 `= NULL`） |


```sql
DROP TABLE IF EXISTS student;

CREATE TABLE student(
	student_id SERIAL,
	name VARCHAR(20),
	major VARCHAR(20),
	score INT,
	PRIMARY KEY(student_id)
);

INSERT INTO student VALUES(1, '小白','英語',50);
INSERT INTO student VALUES(2, '小黃','生物',90);
INSERT INTO student VALUES(3, '小綠','歷史',70);
INSERT INTO student VALUES(4, '小藍','英語',80);
INSERT INTO student VALUES(5, '小黑','化學',20);
```

### 取得所有欄位

```sql
SELECT * FROM student;
```

### 取得name欄位

```sql
SELECT name FROM student;
```

### 取得name,major欄位

```sql
SELECT name,major FROM student;
```

### 排序預設為 ASC（由小到大）

```sql
SELECT *
FROM student
ORDER BY score
```

### 排序由高至低

```sql
SELECT *
FROM student
ORDER BY score DESC
```


### order by也可以多個欄位

```sql
SELECT *
FROM student
ORDER BY score,student_id
```

### limit限制筆數

```sql
SELECT *
FROM student
LIMIT 3
```

### limit和order by整合：分數最低的3筆

```sql
SELECT *
FROM student
ORDER BY score
LIMIT 3
```

### limit和order by整合：分數最高的3筆

```sql
SELECT *
FROM student
ORDER BY score DESC
LIMIT 3
```

### 過濾WHERE

```sql
SELECT *
FROM student
WHERE major = '英語'
```

### 過濾WHERE,AND

```sql
SELECT *
FROM student
WHERE major = '英語' AND student_id=1
```

### 過濾WHERE,OR

```sql
SELECT *
FROM student
WHERE major = '英語'  OR score > 60
```

### 過濾WHERE,使用IN,等同於使用OR

```sql
SELECT *
FROM student
WHERE major = '英語'  OR major='生物' OR major='歷史'
```

```sql
SELECT *
FROM student
WHERE major in('英語','生物','歷史')
```

## 🤖 不寫 SQL，用 Prompt 完成

> 在 Claude Desktop 使用[第 3 章](../MCP操作資料庫/2_用中文查詢資料庫/#6-準備第-4-章設定可寫入的連線)設定的 **`postgres-sql`**（可寫入，連到 `sql_tutorial` 資料庫）。
> 每個 prompt 執行後，點開工具呼叫（`execute_sql`），**對照 AI 執行的 SQL 和上面學的是否一樣**。

**先準備資料：**

> 用 postgres-sql 重新建立 student（如果存在先刪除）：student_id 是 SERIAL 主鍵，name、major 是 VARCHAR(20)，score 是 INT。新增 5 位學生：(1, 小白, 英語, 50)、(2, 小黃, 生物, 90)、(3, 小綠, 歷史, 70)、(4, 小藍, 英語, 80)、(5, 小黑, 化學, 20)。

| # | Prompt | 對照上面 | 答案 |
|:---:|---|---|---|
| 1 | 列出所有學生的所有欄位 | 取得所有欄位 | 5 筆 |
| 2 | 只列出學生的姓名 | 取得name欄位 | 5 個姓名 |
| 3 | 列出姓名和主修 | 取得name,major欄位 | |
| 4 | 依分數由低到高列出所有學生 | 排序預設為 ASC | 小黑 → 小白 → 小綠 → 小藍 → 小黃 |
| 5 | 依分數由高到低 | 排序由高至低 | 小黃 → 小藍 → 小綠 → 小白 → 小黑 |
| 6 | 依分數排序，分數一樣再依學號排序 | order by 多個欄位 | |
| 7 | 隨便給我 3 筆學生資料 | limit限制筆數 | 3 筆 |
| 8 | 分數最低的 3 位學生 | 分數最低的3筆 | 小黑、小白、小綠 |
| 9 | 分數最高的 3 位學生 | 分數最高的3筆 | 小黃、小藍、小綠 |
| 10 | 主修英語的學生 | 過濾WHERE | 小白、小藍 |
| 11 | 主修英語而且學號是 1 的學生 | 過濾WHERE,AND | 小白 |
| 12 | 主修英語，或分數超過 60 分的學生 | 過濾WHERE,OR | 小白、小黃、小綠、小藍 |
| 13 | 主修是英語、生物或歷史的學生 | 使用IN | 小白、小黃、小綠、小藍 |

✅ 檢查重點：
- 第 9 題：AI 要先 `ORDER BY score DESC` 再 `LIMIT 3`。如果沒有排序就 LIMIT，取到的不一定是最高的
- 第 12 題：「英語」和「超過 60 分」之間是 `OR` 不是 `AND`
- 第 13 題：AI 用 `IN (...)` 或三個 `OR` 都對，結果一樣
