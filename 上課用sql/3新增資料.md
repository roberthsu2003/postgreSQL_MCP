## 新增資料

### 語法

```sql
INSERT INTO table1(column1, column2, …)
VALUES (value1, value2, …);
```

### 建立student資料表

```sql
CREATE TABLE student(
	student_id SERIAL,
	name VARCHAR(20),
	major VARCHAR(20),
	PRIMARY KEY(student_id)
);
```


### 新增資料

```sql
INSERT INTO student VALUES(1,'小白','歷史');
INSERT INTO student VALUES(2,'小黑','生物');
INSERT INTO student VALUES(3,'小綠',NULL);
```

### primary key 不可以重覆
- 重覆會出錯

```sql
INSERT INTO student VALUES(3,'小藍','小藍');
```

**錯誤訊息**: `ERROR: duplicate key value violates unique constraint "student_pkey"`

### 沒有填入的資料會成為NULL

```sql
INSERT INTO student(major,student_id) VALUES('英語',5);
```

### ⚠️ 自己指定 SERIAL 的值要注意

上面都是自己指定 `student_id`，SERIAL 的自動編號**不會跟著前進**，下一次不指定 `student_id` 時會從 1 開始，和已經存在的 1 衝突：

```sql
INSERT INTO student(name, major) VALUES('小紫','數學');
-- ERROR: duplicate key value violates unique constraint "student_pkey"
```

解決方式：讓自動編號從目前最大值繼續

```sql
SELECT setval(pg_get_serial_sequence('student', 'student_id'), (SELECT MAX(student_id) FROM student));
```
