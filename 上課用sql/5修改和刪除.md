## 修改和刪除資料

### 語法:

```sql
UPDATE table_name
SET column1 = value1,
    column2 = value2,
    ...
WHERE condition;
```


```sql
DELETE FROM table_name
WHERE condition;
```

```sql
DROP TABLE IF EXISTS student;
CREATE TABLE student(
	student_id SERIAL,
	name VARCHAR(20),
	major VARCHAR(20),
	score INT,
	PRIMARY KEY(student_id)
);
INSERT INTO student VALUES(1, '小白','英語',50);
INSERT INTO student VALUES(2, '小黃','生物',90);
INSERT INTO student VALUES(3, '小綠','歷史',70);
INSERT INTO student VALUES(4, '小藍','英語',80);
INSERT INTO student VALUES(5, '小黑','化學',20);
SELECT * FROM student;
```

### 將英語更改為英語文學

```sql
UPDATE student
SET major='英語文學'
WHERE major='英語';
```

### 將student_id 3,改為生物

```sql
UPDATE student
SET major='生物'
WHERE student_id=3;
```

### 將生物和化學改為生化

```sql
UPDATE student
SET major='生化'
WHERE major='生物' OR major='化學';
```

### 將student_id是1的,同時修改name和major

```sql
UPDATE student
SET name='小灰',major='物理'
WHERE student_id=1;
```

### 沒有where

```sql
UPDATE student
SET major='物理';
```

### 刪除student_id=3的資料

```sql
DELETE FROM student
WHERE student_id=3;
```

### 刪除name=小灰同時major=物理

```sql
DELETE FROM student
WHERE name='小灰' AND major='物理';
```

### 刪除score < 60的資料

```sql
DELETE FROM student
WHERE score < 60;
```

### 刪除score不等於80的資料

```sql
DELETE FROM student
WHERE score <> 80;
```

### 刪除所有資料

```sql
DELETE FROM student;
```

> ⚠️ 沒有 WHERE 的 UPDATE、DELETE 會影響**所有資料**，執行前一定要再確認一次。

## 🤖 不寫 SQL，用 Prompt 完成

> 在 Claude Desktop 使用[第 3 章](../MCP操作資料庫/2_用中文查詢資料庫/#6-準備第-4-章設定可寫入的連線)設定的 **`postgres-sql`**（可寫入，連到 `sql_tutorial` 資料庫）。
> 每個 prompt 執行後，點開工具呼叫（`execute_sql`），**對照 AI 執行的 SQL 和上面學的是否一樣**。

**先準備資料：**

> 用 postgres-sql 重新建立 student（如果存在先刪除）：student_id 是 SERIAL 主鍵，name、major 是 VARCHAR(20)，score 是 INT。新增 5 位學生：(1, 小白, 英語, 50)、(2, 小黃, 生物, 90)、(3, 小綠, 歷史, 70)、(4, 小藍, 英語, 80)、(5, 小黑, 化學, 20)。

> ⚠️ 修改、刪除的 prompt 都加上「**先列出會受影響的資料，等我確認再執行**」。Postgres MCP Pro 執行 UPDATE、DELETE 後只會回傳「No results」，**不會告訴你改了幾筆**，執行後一定要再查詢確認。

| # | Prompt | 對照上面 | 會影響 |
|:---:|---|---|---|
| 1 | 把主修是英語的改成英語文學，先列出會被修改的資料，等我確認再執行 | 將英語更改為英語文學 | 小白、小藍 |
| 2 | 學號 3 的主修改成生物 | 將student_id 3,改為生物 | 小綠 |
| 3 | 主修是生物和化學的，都改成生化 | 將生物和化學改為生化 | 小黃、小綠、小黑 |
| 4 | 學號 1 的姓名改成小灰、主修改成物理 | 同時修改name和major | 小白 |
| 5 | 把主修改成物理 | 沒有where | ⚠️ 見下方 |
| 6 | 刪除學號 3 的學生 | 刪除student_id=3的資料 | 小綠 |
| 7 | 刪除姓名是小灰而且主修是物理的學生 | 刪除name=小灰同時major=物理 | 小灰 |
| 8 | 刪除分數低於 60 分的學生 | 刪除score < 60的資料 | 小黑 |
| 9 | 刪除分數不是 80 分的學生 | 刪除score不等於80的資料 | 小黃 |
| 10 | 刪除所有學生資料，但保留資料表 | 刪除所有資料 | 小藍 |

✅ 檢查重點：
- **第 5 題是陷阱**：沒有說「誰」要改成物理。AI 應該先問你「是所有學生嗎？」。如果 AI 直接執行沒有 WHERE 的 UPDATE，**所有學生**都會被改掉
- 確認是要全部修改後，再說「對，所有學生都改成物理」，結果和上面「沒有where」一樣
- 第 10 題：AI 用的是 `DELETE FROM student`（保留資料表），而不是 `DROP TABLE`（連資料表一起刪除）
