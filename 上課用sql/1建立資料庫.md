## 資料庫

### 新增資料庫

```sql
CREATE DATABASE SQL_TUTORIAL;
```

> 名稱沒有加雙引號時，PostgreSQL 會自動轉成小寫，實際建立的是 `sql_tutorial`。

### 查詢資料庫


```
使用psql語法
postgres=# \l
```

或使用 SQL：

```sql
SELECT datname FROM pg_database;
```

### 刪除資料庫

```sql
DROP DATABASE SQL_TUTORIAL;
```

## 🤖 不寫 SQL，用 Prompt 完成

> 在 Claude Desktop 使用[第 3 章](../MCP操作資料庫/2_用中文查詢資料庫/#6-準備第-4-章設定可寫入的連線)設定的 **`postgres-sql`**（可寫入，連到 `sql_tutorial` 資料庫）。
> 每個 prompt 執行後，點開工具呼叫（`execute_sql`），**對照 AI 執行的 SQL 和上面學的是否一樣**。

**Prompt 1：查詢資料庫**

> 列出這台 PostgreSQL 上有哪些資料庫。

✅ 等同 psql 的 `\l`。AI 通常會執行 `SELECT datname FROM pg_database`。

**Prompt 2：建立資料庫**

> 建立一個 SQL_TUTORIAL 資料庫。

❌ **這題 AI 做不到**，會出現 `CREATE DATABASE cannot run inside a transaction block`。Postgres MCP Pro 執行 SQL 時都包在交易中，而 `CREATE DATABASE`、`DROP DATABASE` 不能在交易中執行。

改成請 AI 產生 SQL，自己到 pgAdmin 執行：

> 給我建立 SQL_TUTORIAL 資料庫的 SQL，我自己在 pgAdmin 執行。

> ⚠️ `postgres-sql` 連到的就是 `sql_tutorial`。練習完 `DROP DATABASE` 後，記得再建立回來，後面的課程才能繼續使用。
