# 產品需求文件 (PRD)：員工排班考勤與薪資試算 Tkinter 系統

* **專案代號**：`HR-Tkinter-Attendance-Payroll`
* **適用職務**：**人資 (HR)、考勤管理員、計薪出納、門市督導**
* **開發模式**：規格驅動開發 (SDD, Spec-Driven Development)
* **資料庫環境**：PostgreSQL / Supabase (對應 [`hr_attendance.sql`](../../範例資料庫/中文範例資料庫/hr_attendance.sql))
* **前端框架**：Python 內建 **Tkinter** (個人桌面視窗 GUI)
* **資料庫存取方式**：Python 原生手寫 SQL (`psycopg2`)，不使用 ORM 遮蔽 SQL

---

## 1. 職場痛點與專案目標

中小企業或門市的人資主管，每個月初核算薪資與排班時面臨大量手工 Excel 痛點：
1. **排班衝突與違規風險**：手排班容易撞期，或不小心讓員工連續上班超過 6 天違反勞動法規。
2. **打卡工時手動加總容易算錯**：要從打卡鐘匯出的 CSV 裡手動計算遲到幾分鐘、加班幾小時，公式錯一格全店薪資全錯。
3. **請假扣款繁瑣**：事假扣全薪、病假扣半薪、特休不扣薪，人工核對費時耗力。

本專案旨在將 `hr_attendance.sql` 資料庫開發為**免安裝繁雜環境、雙擊即可啟動的 Tkinter 個人桌面小工具**，自動化結算工時與薪資明細！

---

## 2. 資料庫結構 (由學生在 DBeaver 執行 hr_attendance.sql 建立)

包含 5 張標準關聯表：
1. **`hr_departments`**：部門主檔
2. **`hr_employees`**：員工資料（含底薪 `base_salary` 與法定換算時薪 `hourly_rate`）
3. **`hr_shifts`**：排班表（防呆設定同員工同日不可重複排班）
4. **`hr_attendance_records`**：每日打卡明細（上班、下班、遲到註記、加班時數）
5. **`hr_leave_requests`**：請假審批單（事假/病假/特休/公假）

---

## 3. 前端介面與功能需求 (Tkinter 桌面視窗)

### 3.1 員工考勤與打卡月曆視圖 (`ttk.Treeview`)
- **月份與部門篩選**：下拉選單切換月份（如 2024-03）與部門。
- **每日打卡明細表格**：顯示工號、姓名、日期、上班打卡、下班打卡、實際工時、加班時數、狀態（正常/遲到/加班）。

### 3.2 智能薪資結算計算機 (Payroll Calculator)
- 點選特定員工或點擊「一鍵結算全店薪資」：
  - 手寫 SQL 加總當月正常工時、累計加班時數（乘以 1.34 / 1.67 法定加班費率）。
  - 手寫 SQL 統計請假時數（病假半薪、事假全扣）。
  - 自動算出「實發薪資總額」並條列於薪資明細卡片中。
