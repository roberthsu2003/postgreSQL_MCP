# todolist：網路商店訂單小工具（範例成品）

> 一次只做一項，親自驗收通過才打勾。開始前若資料已被改亂，請在 DBeaver 執行 `TRUNCATE TABLE order_items, orders, products, customers RESTART IDENTITY;` 後重新執行你在步驟 3 產生的交易檔，恢復初始資料。

## [ ] 1. 打開視窗，確認連得上資料庫

- **要做什麼**：做出主視窗，連線資料庫並顯示狀態。
- **怎麼操作**：執行 `python app.py`。
- **應該看到**：視窗顯示「已連線，10 張訂單、7 項商品」。

## [ ] 2. 查訂單（S1）

- **要做什麼**：輸入訂單編號，顯示明細與總額。
- **怎麼操作**：輸入 1001 後查詢；再輸入 9999 後查詢。
- **應該看到**：第一次顯示保溫鋼杯 450 × 2、快充行動電源 890 × 1，總額 1,790；第二次顯示「查無此訂單」。

## [ ] 3. 會員購買紀錄（S2）

- **要做什麼**：輸入會員姓名，顯示購買品項。
- **怎麼操作**：輸入「林志明」。
- **應該看到**：共 4 筆，日期由早到晚，無線藍牙耳機兩筆單價分別是 1,290 和 1,190。

## [ ] 4. 未售出商品、未下單會員（S4）

- **要做什麼**：列出還沒賣出的商品和還沒下單的會員。
- **怎麼操作**：打開名單。
- **應該看到**：商品「輕量登山背包」、會員「張大同」。

## [ ] 5. 調整售價（S3）

- **要做什麼**：修改商品目前售價，舊訂單金額不變。
- **怎麼操作**：把快充行動電源改成 950，再查訂單 1001。
- **應該看到**：商品售價顯示 950；訂單 1001 總額仍然是 1,790，快充行動電源的成交單價仍是 890。

## [ ] 6. 建立訂單（S5）

- **要做什麼**：為會員建立有多項商品的訂單，成交單價自動帶入目前售價。
- **怎麼操作**：為張大同建立訂單 1011，付款方式信用卡，買輕量登山背包 1 個、快充行動電源 2 個；再用 1011 建立一次。
- **應該看到**：第一次成功，總額 3,480；第二次顯示「訂單編號已存在」，訂單數不變。

## [ ] 7. 刪除訂單（S5）

- **要做什麼**：刪除訂單前先確認，明細一併刪除。
- **怎麼操作**：刪除訂單 1011，先按取消；再按一次刪除並確認；查詢 1011；查看會員名單。
- **應該看到**：取消時訂單仍在；確認後查詢顯示「查無此訂單」，張大同仍在會員清單中。

## [ ] 8. 錯誤處理

- **要做什麼**：輸入錯誤或連線失敗時顯示中文訊息，程式不會當掉。
- **怎麼操作**：數量輸入 0；售價輸入「abc」；把 `.env` 的密碼改錯後重新開啟，測完改回來。
- **應該看到**：數量為 0 時顯示「數量必須大於 0」，輸入文字時顯示「請輸入數字」，資料都不變；連線錯誤時顯示「無法連線資料庫」，視窗不會直接消失。
