## 這個專案要解決的問題

業務小安把所有訂單記在 [`網路商店訂單表.xlsx`](./網路商店訂單表.xlsx)。一張訂單買幾項商品就佔幾列，會員資料一再重複；還沒賣出的新商品和還沒下單的會員，只能用一堆空白欄位硬塞。

更麻煩的是，商品調價後，舊訂單的金額到底該算多少？這個專案會用正確的結構回答這個問題。
