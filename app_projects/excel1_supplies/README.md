# 實戰專案 1｜耗材庫存表：從一張 Excel 到個人 App

> 💻 Excel + DBeaver + AI 工具（資料庫：`supplies`）｜ 🎯 學完你會：把單一工作表搬進資料庫，用 SQL 完成工作需求，再請 AI 做成自己的 App

[← 回實戰專案大綱](../實戰專案大綱.md)

## 這個專案要解決的問題

總務小林用 [`耗材庫存表.xlsx`](./耗材庫存表.xlsx) 管理公司的影印紙、碳粉匣和文具。每次有人領用都要手動改數字，常常斷貨了才發現，也曾因為品號打重複而盤點對不上。

你會把 SQL 章節學到的語法用在這張 Excel 上，最後做出小林能每天使用的桌面工具。

## 開始之前

- [ ] 學完 [DDL 章節](../../SQL語法教學/README.md#-ddl蓋結構)，可以開始步驟 1、2
- [ ] 學完 [DML-1 到 DML-3](../../SQL語法教學/README.md#-dml操作資料)，可以開始步驟 3、4
- [ ] Tkinter 可以使用（步驟 5 才需要）：在終端機執行 `python3 -m tkinter`，會跳出一個小視窗

> [!NOTE]
> Windows 和 python.org 下載的 Python 已經包含 Tkinter。Mac 用 Homebrew 安裝的 Python 要另外執行 `brew install python-tk`。

## 專案流程

| 步驟 | 做什麼 | 誰來做 |
|:---:|---|:---:|
| 1 | [讀懂 Excel 與故事](./1_讀懂Excel與故事.md)：決定每一欄的規格 | 你 |
| 2 | [手寫 DDL](./2_手寫DDL.md)：建立資料庫和資料表 | 你 |
| 3 | [AI 產生資料交易檔](./3_AI產生資料交易檔.md)：轉資料、匯入、對帳 | AI 轉資料，你驗收 |
| 4 | [DML 回答故事](./4_DML回答故事.md)：用 SQL 完成五個需求 | 你 |
| 5 | 建立 [AI 唯讀帳號](./prompts/00_建立唯讀帳號.sql)，請 AI [讀結構寫 PRD](./prompts/01_MCP讀結構產生PRD.md) | AI 寫，你審核 |
| 6 | 請 AI [把 PRD 拆成 todolist](./prompts/02_PRD產生todolist.md) | AI 寫，你審核 |
| 7 | 設定連線：`cp .env.example .env`，填入你的資料庫密碼 | 你 |
| 8 | AI 一次做一項，你一次驗收一項 | AI 寫程式，你驗收 |

> [!IMPORTANT]
> **步驟 2 不能跳。** 資料表是你親手建的，AI 只負責把資料轉成 INSERT。如果表建錯，資料匯入時會整份失敗，這正好幫你檢查結構。

## 檔案說明

| 檔案 | 用途 |

| [`耗材庫存表.xlsx`](./耗材庫存表.xlsx) | 三張工作表：「耗材庫存」25 筆資料、「需求」五則故事、「有問題的資料」測試限制條件用 |

## 為什麼要用唯讀帳號

| 階段 | 用什麼連資料庫 | 能做什麼 |
|---|---|---|
| 步驟 1～4 | 你自己在 DBeaver | 全部親手做 |
| 寫 PRD 時的 AI | `ai_readonly` | 只能看，改不了資料 |
| 做好的 App | `.env` 裡你的帳號 | App 需要扣庫存，所以要能寫入 |

讓 AI 讀真實結構，它就不會編造不存在的欄位。用唯讀帳號，它就算判斷錯誤也動不到你的資料。
