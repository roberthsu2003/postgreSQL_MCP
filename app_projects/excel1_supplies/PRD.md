# PRD：耗材庫存小工具（範例成品）

> 這是範例。你請 AI 產生的內容會略有不同，只要涵蓋相同的故事和驗收條件即可。

## 1. 要解決的問題

總務人員用 Excel 管理公司耗材，每次領用都要手動改數字，容易斷貨才發現，品號也可能重複。這個工具讓總務人員在自己的電腦上，查詢、領用和登記耗材。

**使用者**：一位總務人員，以及需要看庫存金額的總務主管。

## 2. 這次不做的事

- 不做帳號登入和權限管理
- 不做網站或多人同時使用
- 不做採購單與領用歷史紀錄
- 不匯入 Excel（資料已經在資料庫裡）

## 3. 功能

| 功能 | 故事 | 使用的 SQL（`我的查詢.sql`） |
|---|:---:|---|
| 補貨清單 | S1 | 查詢庫存到達安全水位的品項 |
| 搜尋耗材 | S2 | 依品名關鍵字查詢 |
| 登記領用 | S3 | 扣除現有庫存 |
| 新增耗材 | S4 | 新增一筆 |
| 刪除耗材 | S4 | 依品號刪除一筆 |
| 庫存總金額 | S5 | 加總單價乘以現有庫存 |

## 4. 驗收條件

以下數字以 `supplies_full.sql` 的初始資料為準。

### 補貨清單（S1）
- 我打開補貨清單，應該看到 **9 項**耗材，包含品號、品名、現有庫存、安全庫存和缺口。
- 缺口最大的排在最前面，第一批是便利貼和黑色原子筆，缺口都是 5。
- 庫存剛好等於安全庫存的濕紙巾也要出現，缺口是 0。

### 搜尋耗材（S2）
- 我輸入「碳粉」，應該看到 **4 項**碳粉匣，以及它們的庫存和存放位置 `3F 總務庫房 C-03`。
- 我輸入資料裡沒有的字，應該看到「查無資料」，而不是錯誤。

### 登記領用（S3）
- 我選擇黑色原子筆、領用 2 支，庫存應該從 45 變成 43。
- 我選擇黑色碳粉匣、領用 5 支，應該看到「庫存不足」的提示，庫存仍然是 1。

### 新增耗材（S4）
- 我填入新品號 `STA-GLUE-01`、品名「口紅膠」等資料，清單應該多出這一項。
- 我再用同一個品號新增一次，應該看到「品號已存在」，資料不會增加。

### 刪除耗材（S4）
- 我選擇 `STA-GLUE-01` 並確認刪除，只有這一項消失，其他品項不受影響。
- 按下刪除時要先詢問確認，取消的話不會刪除。

### 庫存總金額（S5）
- 打開工具，應該看到庫存總金額 **66,474**。
- 登記領用後，金額要跟著更新。

## 5. 使用的資料

資料來自 `supplies` 資料表：

| 欄位 | 意思 | 用在 |
|---|---|---|
| `item_code` | 品號 | 全部功能 |
| `name` | 品名 | 全部功能 |
| `spec` | 規格 | 新增 |
| `category` | 類別：紙張、碳粉墨水、文具、清潔用品 | 新增 |
| `unit` | 單位 | 新增 |
| `unit_price` | 單價 | 新增、總金額 |
| `current_stock` | 現有庫存 | 補貨清單、領用、總金額 |
| `safety_stock` | 安全庫存 | 補貨清單 |
| `location` | 存放位置 | 搜尋、新增 |
| `last_checked` | 最後盤點日 | 這次不使用 |
