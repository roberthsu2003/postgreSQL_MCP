## 教到哪裡可以用（教師對照表）

照第 4 章的順序上課，**教完左邊這一課，就可以帶學生做右邊的專案**。每個專案的步驟 1～4 專注於手寫 SQL、AI 交易與微軟 MCP 查詢驗證；步驟 5～8 才進入 PRD 與桌面 App。

| 教完這一課 | 可以做 | 步驟 | 課堂上要提醒 |
|---|---|:---:|---|
| DDL-5 限制條件 | [專案 1 耗材庫存表](./excel1_supplies/README.md) | 1、2 | 步驟 2 採任務挑戰制，務必讓學生先自己敲 `CREATE TABLE` 再展開對照 |
| DML-3 修改與刪除 | [專案 1 耗材庫存表](./excel1_supplies/README.md) | 3、4 | 步驟 4 共 10 題 DML，每題皆須在 DBeaver 跑過再用微軟 MCP Prompt 驗證 |
| DML-6 JSONB | [專案 2 IT 設備規格表](./excel2_devices/README.md) | 1～4 | 空白的規格不放進 JSON；提醒 `jsonb_set` 數字不包雙引號 |
| 一對多入門 | [專案 3 打卡表](./excel3_attendance/README.md) | 1～4 | 要求 AI 發現 E05 部門矛盾時先發問，不直接寫入 |
| 進階-2 關聯新增 | [專案 4 差旅報銷單](./excel4_expense/README.md) | 1～4 | 提醒學生檢查 `setval` 是否接在手動編號 `INSERT` 後面 |
| 進階-3 關聯搜尋 | [專案 5 網路商店訂單](./excel5_shop/README.md) | 1～4 | 強調 `products.price`（目前售價）vs `order_items.unit_price`（成交單價） |
| 進階-5 模糊搜尋 | [專案 6 客服案件紀錄](./excel6_tickets/README.md) | 1～4 | 要求 AI 產生交易檔時不可偷改 `WiFi`/`wifi`/`Wi-Fi` 大小寫 |
| 進階-7 綜合連結 | [專案 7 教育訓練報名表](./excel7_training/README.md) | 1～4 | 強調 `LEFT JOIN` 的條件放 `ON` 與 `WHERE` 的結果差異 |
| 進階-9 ON DELETE | [專案 8 連鎖門市月報](./excel8_stores/README.md) | 1～4 | 取消 CSV 匯入精靈，改用 Excel 跨月精選樣本（30 筆＋4 月 7 筆）由 AI 產生交易檔 |
| 學完第 4 章 | 任一專案 | 5～8 | 建議挑 1～2 個專案做到 App；全程使用第 1 章設定好的 `@microsoft/postgres-mcp` |

## 每個專案的固定流程

```mermaid
flowchart LR
    A["Excel<br>與 user story"] --> B["手寫 DDL<br>（任務挑戰＋MCP驗結構）"]
    B --> C["AI 依結構產生<br>Transaction 交易檔"]
    C --> D["DBeaver 執行<br>對帳 ＋ ROLLBACK 實測"]
    D --> E["10 題 DML 任務挑戰<br>手寫 SQL ＋ 微軟 MCP Prompt"]
    E --> F["微軟 MCP 讀結構<br>寫 PRD.md"]
    F --> G["todolist.md"]
    G --> H["個人桌面 App"]
```

| 工作 | 學生 | AI（含 Microsoft Postgres MCP） |
|---|:---:|:---:|
| 寫 story、欄位規劃與拆表思考 | ✅ 親手規劃 | 僅提示檢查，先不給 SQL |
| 手寫 DDL（建庫、建表、測壞資料） | ✅ 在 DBeaver 親手敲與執行 | 透過 MCP 唯讀檢查表結構是否遺漏 |
| 把 Excel 轉成 SQL Transaction | ✅ 審查並執行、故意測 `ROLLBACK` | 依學生 DDL 產出 `BEGIN...COMMIT`（不寫入 DB） |
| 10 題 DML 練習（S1～S5 ＋ E1～E5） | ✅ 在 DBeaver 寫進 `我的查詢.sql` | 依每題 Prompt 用 MCP 唯讀查詢、核對結果 |
| PRD.md、todolist.md 與桌面 App | 審核、逐項驗收畫面 | ✅ 用微軟 MCP 讀結構並產生程式 |

> [!NOTE]
> **講師對照／自動化測試檔**：原本散落於各專案的 16 份 `*_data.sql` 與 `*_full.sql`（以及原 `門市銷售明細_202404.csv`）已統一移入 [`_teacher_reference/`](./_teacher_reference/README.md)，**不提供於學員教學步驟中直接匯入**，確保學生落實手寫建表與 AI 交易檔實作。
