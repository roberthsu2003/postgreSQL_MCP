[← 回第 5 章實戰專案](../README.md)

## 這個專案要解決的問題

行政小蓉每個月複製一份 Excel，第一季累積了 [1 月](../../範例資料庫/excel範例/連鎖門市月報表/門市銷售明細_202401.xlsx)、[2 月](../../範例資料庫/excel範例/連鎖門市月報表/門市銷售明細_202402.xlsx)、[3 月](../../範例資料庫/excel範例/連鎖門市月報表/門市銷售明細_202403.xlsx)三個檔案，共 782 列。老闆一問跨月營收，就要開很多檔案湊數字。

這個專案要把資料整合進資料庫。之後每個月只要匯入新的 CSV，報表就自動更新。
