# 實戰專案 8｜門市月報：不用匯入檔案、把跨月明細正規化並用交易檔持續累加

> 💻 Excel + DBeaver + AI 工具（資料庫：`store_sales`）｜ 🎯 學完你會：用 `raw_sales` 暫存表把流水帳拆成六張關聯表、用 AI 產生可重複執行（冪等）的 `BEGIN ... COMMIT` 交易檔，並用 MCP 完成跨月對帳與分析

[← 回第 5 章實戰專案](../README.md)

## 這個專案要解決的問題

營運經理阿哲每個月都會收到各門市的銷售明細（欄位完全相同，每列包含門市、店員、會員、商品、付款與訂單狀態）。只看單一檔案時，常常遇到三個痛點：跨月對比麻煩、同名會員（例如兩位都叫「謝哲瑋」或「劉欣宜」）容易混在一起、重複收到同月份明細時又怕寫重複或把原資料蓋壞。

這個專案**不使用檔案匯入精靈**，你會親手用 `CREATE TABLE` 建好「六張核心資料表＋一張 `raw_sales` 暫存表」，把 [`門市月報_需求與樣本.xlsx`](./門市月報_需求與樣本.xlsx) 的第一季 31 筆精選樣本交給 AI 轉成純交易 SQL 歸位、三方對帳後，在 DBeaver 完成 **10 道跨月查詢與交易實作題**（包含直接轉入 `4月新銷售明細` 並驗證重複執行不重複寫入！），同時搭配 **Microsoft Postgres MCP** 做唯讀查詢與雙重驗收。
