# todolist：門市月報小工具（範例成品）

> 一次只做一項，親自驗收通過才打勾。開始前請確保已在 DBeaver 完成步驟 3 的第一季樣本資料寫入（22 張訂單、5 家門市）。若測試過程中資料被改亂，可用 `TRUNCATE order_items, orders, customers, products, staff, stores, raw_sales RESTART IDENTITY;` 清空並重跑步驟 3 產生的交易檔。

## [ ] 1. 打開視窗，確認連得上資料庫

- **要做什麼**：做出主視窗，連線資料庫並顯示狀態。
- **怎麼操作**：執行 `python app.py`。
- **應該看到**：視窗顯示「已連線，22 張訂單、5 家門市」。

## [ ] 2. 各門市月營收（S1）

- **要做什麼**：顯示各門市每月的已完成營業額。
- **怎麼操作**：打開月營收報表。
- **應該看到**：15 列，第一列是 `台中逢甲店 2024-01`、`95`，下方合計 `3,125`。

## [ ] 3. 熱銷排行（S2）

- **要做什麼**：顯示銷售數量前 5 名的商品（同數量比營業額）。
- **怎麼操作**：打開熱銷排行。
- **應該看到**：5 項商品，第一名 `摩卡咖啡` 5 個（575 元），第二名 `黑椒里肌吐司` 5 個（375 元）。

## [ ] 4. 忠誠會員名單（S3）

- **要做什麼**：列出 1、2、3 月都有已完成消費的會員。
- **怎麼操作**：打開忠誠會員名單。
- **應該看到**：3 位會員，第一位 `謝哲瑋（0963-728-214）` 955 元，另一位 `謝哲瑋（0943-645-351）` 425 元也在名單上，兩位同名分開呈現。

## [ ] 5. 績優店員（S4）

- **要做什麼**：列出業績高於第一季全體店員平均（313 元）的店員。
- **怎麼操作**：打開績優店員名單。
- **應該看到**：4 位店員，第一名 `曾思妤（高雄巨蛋店）` 950 元，第四名 `蔡哲瑋（新竹巨城店）` 325 元。

## [ ] 6. 新月份交易歸位功能（S5）

- **要做什麼**：支援貼入或讀取由 AI 依新月份 Excel 產生的純 SQL 交易區塊（或執行既定 `BEGIN ... COMMIT` 交易腳本將 `raw_sales` 資料寫入六張表），並顯示新增訂單結果。
- **怎麼操作**：載入或貼入「`4月新銷售明細`」交易 SQL 執行一次；再重複執行同一個交易一次。
- **應該看到**：第一次顯示「讀取 7 筆，新增 5 張訂單」，訂單總數從 22 變成 27，2024-04 出現在月營收報表；第二次重複執行顯示「新增 0 張訂單」，訂單總數仍是 27。

## [ ] 7. 錯誤處理

- **要做什麼**：SQL 交易違反約束或連線失敗時顯示中文訊息，程式不會當掉（並自動 `ROLLBACK` 保護原資料）。
- **怎麼操作**：貼入一筆數量為 `0` 的異常明細嘗試寫入；再把 `.env` 密碼改錯後重新開啟程式，測完改回來。
- **應該看到**：異常明細被 `ROLLBACK` 擋下並顯示中文錯誤提示，訂單總數不變；連線錯誤時顯示「無法連線資料庫」，視窗不會直接消失。
