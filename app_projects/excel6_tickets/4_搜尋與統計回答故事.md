## S1｜用關鍵字找案件

先用 `LIKE` 試試：

```sql
SELECT ticket_id FROM tickets WHERE description LIKE '%wifi%' ORDER BY ticket_id;
```

**執行結果**：只有 `T005`、`T020` 兩筆。`LIKE` 分大小寫，WiFi 和 WIFI 都漏掉了。

改用 `ILIKE`，結果增加到 5 筆，但 T013 的 `Wi-Fi` 中間有橫線，還是找不到。把兩種寫法都列出來：

```sql
SELECT ticket_id AS 案件,
       created_on AS 日期,
       description AS 問題描述,
       status AS 狀態
FROM tickets
WHERE description ILIKE '%wifi%' OR description ILIKE '%wi-fi%'
ORDER BY ticket_id;
```

**執行結果**

| 案件 | 日期 | 問題描述 | 狀態 |
|---|---|---|---|
| T001 | 2024-01-03 | WiFi 連不上，重開機也沒用 | 已結案 |
| T005 | 2024-01-12 | wifi 訊號不穩，視訊會議常斷線 | 已結案 |
| T009 | 2024-01-25 | 會議室 WIFI 斷線 | 已結案 |
| T013 | 2024-02-06 | Wi-Fi 密碼過期，無法連線 | 已結案 |
| T020 | 2024-03-01 | wifi 速度很慢 | 處理中 |
| T028 | 2024-03-20 | 會議室 WiFi 無法連上投影機 | 處理中 |

## S2｜各分類的件數

`FILTER` 可以在同一列算出不同條件的數字：

```sql
SELECT c.name AS 分類,
       COUNT(*) AS 總件數,
       COUNT(*) FILTER (WHERE t.status <> '已結案') AS 未結案
FROM tickets t
JOIN categories c ON t.category_id = c.category_id
GROUP BY c.name
ORDER BY 未結案 DESC, c.name;
```

**執行結果**

| 分類 | 總件數 | 未結案 |
|---|---:|---:|
| 軟體操作 | 8 | 5 |
| 網路連線 | 8 | 3 |
| 硬體設備 | 7 | 2 |
| 帳號權限 | 7 | 1 |

## S3｜未結案達 3 件的人員

分組前的條件放 `WHERE`，分組後的條件放 `HAVING`：

```sql
SELECT a.name AS 處理人員,
       a.extension AS 分機,
       COUNT(*) AS 未結案
FROM tickets t
JOIN agents a ON t.agent_id = a.agent_id
WHERE t.status <> '已結案'
GROUP BY a.agent_id, a.name, a.extension
HAVING COUNT(*) >= 3
ORDER BY 未結案 DESC;
```

**執行結果**

| 處理人員 | 分機 | 未結案 |
|---|---|---:|
| 張育誠 | 104 | 5 |
| 陳怡君 | 101 | 3 |

## S4｜每月案件數

```sql
SELECT TO_CHAR(created_on, 'YYYY-MM') AS 月份,
       COUNT(*) AS 案件數
FROM tickets
GROUP BY TO_CHAR(created_on, 'YYYY-MM')
ORDER BY 月份;
```

**執行結果**

| 月份 | 案件數 |
|---|---:|
| 2024-01 | 10 |
| 2024-02 | 9 |
| 2024-03 | 11 |

## S5｜結案

`WHERE` 多加一個條件，已經結案的案件就不會被改到：

```sql
BEGIN;

UPDATE tickets
SET status = '已結案', closed_on = '2024-03-28'
WHERE ticket_id = 'T030' AND status <> '已結案'
RETURNING ticket_id, status, closed_on;
```

**執行結果**：`T030 | 已結案 | 2024-03-28`

確認無誤就送出：

```sql
COMMIT;
```

把日期改成 `2024-03-29` 再執行一次同樣的 `UPDATE`，會回傳 **0 筆**，結案日期仍然是 3 月 28 日。

## ⚠️ 常見卡關

| 狀況 | 原因 | 怎麼解 |
|---|---|---|
| 搜尋結果太少 | 大小寫或寫法不同 | 改用 `ILIKE`，並列出不同寫法 |
| `WHERE` 不能放 `COUNT` | 聚合條件要放 `HAVING` | 改用 `HAVING` |
| `must appear in the GROUP BY` | 欄位沒分組也沒聚合 | 把欄位加進 `GROUP BY` |

SELECT COUNT(*) AS 前九件 FROM tickets WHERE ticket_id LIKE 'T00_';

</details>

**第 3 題**：哪位客戶的案件最多？

<details>
<summary>看答案</summary>

```sql
SELECT customer_name AS 客戶, COUNT(*) AS 案件數
FROM tickets
GROUP BY customer_name
ORDER BY 案件數 DESC, 客戶
LIMIT 1;
```

結果是 `順發貿易 | 7`。

</details>
