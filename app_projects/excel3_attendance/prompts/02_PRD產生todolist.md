# 步驟 6｜把 `PRD.md` 轉成可執行的 `todolist.md`

> AI 已透過 `@microsoft/postgres-mcp` 讀懂 `employees` 與 `attendance` 關聯結構並產生 `PRD.md`。接著把需求拆解成可逐項測試打勾的 `todolist.md`。

---

## 把下面這段貼給 AI

```text
請閱讀這個資料夾的 PRD.md，幫我拆成一份可逐項實作與驗收的 todolist.md，存在同一個資料夾裡。

拆解原則：
1. 依照使用者故事切分，第一項是「打開視窗顯示已連線、6 位員工、28 筆打卡」，後面依序為 S1 查林志明打卡（5 筆）、S2 遲到名單（5 筆，09:00 不算）、S3 忘打卡名單（3 筆）、S5 新增 E07 吳小安與未打卡名單、S4 黃雅婷調部門（4 筆同步變成業務發展部）、最後一項是錯誤處理。
2. 每一項必須含「要做什麼」、「怎麼操作」、「應該看到什麼具體數字」。
3. 開頭請提醒：「開始前若資料已被測試改亂，請在 DBeaver 執行 TRUNCATE TABLE attendance, employees; 後重新執行你在步驟 3 產生的交易檔，恢復 6 位員工、28 筆打卡初始資料。」（僅使用手動 TRUNCATE 與步驟 3 交易檔還原）。
4. 這個階段只寫 todolist.md，先不要寫任何 Python 程式碼。
```
