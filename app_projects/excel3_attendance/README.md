# 實戰專案 3｜打卡表：把一張總表拆成兩張表

> 💻 Excel + DBeaver + AI 工具（資料庫：`attendance`）｜ 🎯 學完你會：判斷單一工作表該怎麼拆，用外來鍵和 JOIN 接回來，再請 AI 做成自己的 App

[← 回第 5 章實戰專案](../README.md)

## 這個專案要解決的問題

人資小芳每週把打卡機的資料整理成 [`打卡表.xlsx`](./打卡表.xlsx)，每一列都重複填著姓名、部門和職稱。同事調部門時要改很多列，漏改就前後矛盾；新進員工還沒打卡，表上也沒有地方登記。

這個專案要把它拆成「員工」和「打卡紀錄」兩張表，再用 JOIN 接成小芳要看的報表。
