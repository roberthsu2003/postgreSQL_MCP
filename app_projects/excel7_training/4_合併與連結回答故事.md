# 步驟 4｜合併與連結回答故事：疊起來，也不漏掉

> 💻 DBeaver（資料庫：`training`）｜ 🎯 學完你會：用 `UNION` 合併名單，並把 `LEFT JOIN` 的條件放對位置

> 📚 先修：[進階-6 聯集](../../SQL語法教學/12聯集.md)、[進階-7 綜合連結](../../SQL語法教學/13連結.md)。

開一個新的 SQL 分頁，存成 `我的查詢.sql`。請照順序做，S5 會改變資料。

## S1｜一門課的完整名單

兩份名單上下疊起來，第一欄寫上身分：

```sql
SELECT '內部' AS 身分, e.name AS 姓名, e.dept AS 單位, ee.attended AS 出席
FROM employee_enrollments ee
JOIN employees e ON ee.emp_id = e.emp_id
WHERE ee.course_id = 'C02'
UNION ALL
SELECT '外部', g.name, g.company, ge.attended
FROM guest_enrollments ge
JOIN guests g ON ge.guest_id = g.guest_id
WHERE ge.course_id = 'C02'
ORDER BY 身分 DESC, 姓名;
```

**執行結果**：共 7 人，內部 4 人、外部 3 人，包含業務發展部和金福食品兩位陳小華。排序可能因資料庫的語系設定而略有不同。

## S2｜總共有多少人報名過

一個人可能報很多門課，要去除重複，所以用 `UNION`。如果只比對姓名：

```sql
SELECT COUNT(*) AS 用姓名去重
FROM (
    SELECT e.name FROM employee_enrollments ee JOIN employees e ON ee.emp_id = e.emp_id
    UNION
    SELECT g.name FROM guest_enrollments ge JOIN guests g ON ge.guest_id = g.guest_id
) x;
```

**執行結果**：`10`。兩位陳小華被算成同一個人了。

把單位一起比對：

```sql
SELECT e.name AS 姓名, e.dept AS 單位
FROM employee_enrollments ee
JOIN employees e ON ee.emp_id = e.emp_id
UNION
SELECT g.name, g.company
FROM guest_enrollments ge
JOIN guests g ON ge.guest_id = g.guest_id
ORDER BY 姓名, 單位;
```

**執行結果**：**11 人**，這才是正確答案。

## S3｜每門課的內部報名人數

沒有人報名的課也要出現，所以從 `courses` 開始 `LEFT JOIN`：

```sql
SELECT c.course_id AS 課程,
       c.name AS 課程名稱,
       COUNT(ee.emp_id) AS 內部報名
FROM courses c
LEFT JOIN employee_enrollments ee ON c.course_id = ee.course_id
GROUP BY c.course_id, c.name
ORDER BY c.course_id;
```

**執行結果**

| 課程 | 課程名稱 | 內部報名 |
|---|---|---:|
| C01 | Excel 樞紐分析 | 4 |
| C02 | 資料安全入門 | 4 |
| C03 | 簡報表達技巧 | 2 |
| C04 | Power BI 入門 | 2 |
| C05 | AI 工具實務 | 0 |
| C06 | 跨部門溝通 | 2 |

要算 `COUNT(ee.emp_id)`，不是 `COUNT(*)`，否則 C05 會變成 1。

## S4｜每門課的內部出席人數

這題最容易出錯。如果把「有出席」寫在 `WHERE`：

```sql
SELECT c.course_id AS 課程, COUNT(ee.emp_id) AS 出席
FROM courses c
LEFT JOIN employee_enrollments ee ON c.course_id = ee.course_id
WHERE ee.attended = true
GROUP BY c.course_id
ORDER BY c.course_id;
```

**執行結果**：只剩 C01、C02、C03 三門課。`WHERE` 把沒有人出席的課全部濾掉了。

把條件移到 `ON`：

```sql
SELECT c.course_id AS 課程,
       c.name AS 課程名稱,
       COUNT(ee.emp_id) AS 內部出席
FROM courses c
LEFT JOIN employee_enrollments ee
       ON c.course_id = ee.course_id AND ee.attended = true
GROUP BY c.course_id, c.name
ORDER BY c.course_id;
```

**執行結果**

| 課程 | 課程名稱 | 內部出席 |
|---|---|---:|
| C01 | Excel 樞紐分析 | 3 |
| C02 | 資料安全入門 | 3 |
| C03 | 簡報表達技巧 | 2 |
| C04 | Power BI 入門 | 0 |
| C05 | AI 工具實務 | 0 |
| C06 | 跨部門溝通 | 0 |

## S5｜登記出席

`attended IS NULL` 確保只改尚未登記的紀錄：

```sql
BEGIN;

UPDATE employee_enrollments
SET attended = true
WHERE course_id = 'C06' AND emp_id = 'E01' AND attended IS NULL
RETURNING course_id, emp_id, attended;
```

**執行結果**：`C06 | E01 | t`

確認無誤就送出：

```sql
COMMIT;
```

把 `true` 改成 `false` 再執行一次，會回傳 **0 筆**，出席紀錄仍然是 `true`。

## 你的 `我的查詢.sql`

| 故事 | SQL | 未來 App 的功能 |
|:---:|---|---|
| S1 | `UNION ALL` | 課程完整名單 |
| S2 | `UNION`，比對姓名和單位 | 報名總人數 |
| S3 | `LEFT JOIN ... GROUP BY` | 報名人數表 |
| S4 | 條件放在 `ON` | 出席人數表 |
| S5 | `UPDATE ... AND attended IS NULL` | 登記出席 |

## ⚠️ 常見卡關

| 狀況 | 原因 | 怎麼解 |
|---|---|---|
| `each UNION query must have the same number of columns` | 兩段欄位數不同 | 補齊欄位 |
| `LEFT JOIN` 還是少了課程 | 右表條件放在 `WHERE` | 移到 `ON` |
| 沒人報名的課顯示 1 | 用了 `COUNT(*)` | 改成 `COUNT(ee.emp_id)` |
| `ORDER BY` 報錯 | 用了第二段的欄位名稱 | 用第一段的別名 |

SELECT '內部' AS 身分, e.name AS 姓名

**第 2 題**：找出完全沒有內部員工出席的課程（做完 S5 後）。

<details>
<summary>看答案</summary>

```sql
SELECT c.course_id AS 課程, c.name AS 課程名稱
FROM courses c
LEFT JOIN employee_enrollments ee
       ON c.course_id = ee.course_id AND ee.attended = true
GROUP BY c.course_id, c.name
HAVING COUNT(ee.emp_id) = 0
ORDER BY c.course_id;
```

結果是 C04 和 C05。C06 在 S5 登記了一位出席。
