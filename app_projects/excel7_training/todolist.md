# todolist：教育訓練管理小工具（範例成品）

> 一次只做一項，親自驗收通過才打勾。如果想讓資料回到初始狀態，請重新在 DBeaver 用 `TRUNCATE ... RESTART IDENTITY;` 清空並重跑你在步驟 3 產生的資料交易檔。

## [ ] 1. 打開視窗，確認連得上資料庫

- **要做什麼**：做出主視窗，連線資料庫並顯示狀態。
- **怎麼操作**：執行 `python app.py`。
- **應該看到**：視窗顯示「已連線，6 門課程」。

## [ ] 2. 課程完整名單（S1）

- **要做什麼**：輸入課程代碼，列出內部和外部名單。
- **怎麼操作**：輸入 `C02` 後查詢。
- **應該看到**：7 人，內部 4 人、外部 3 人，有標示身分與部門／公司，兩位陳小華都在。

## [ ] 3. 報名總人數（S2）

- **要做什麼**：顯示不重複的報名人數。
- **怎麼操作**：打開報名總人數。
- **應該看到**：11 人。

## [ ] 4. 報名人數表（S3）

- **要做什麼**：列出每門課的內部報名人數。
- **怎麼操作**：打開報名人數表。
- **應該看到**：6 門課，`C01` 是 4 人，`C05` 是 0 人。

## [ ] 5. 出席人數表（S4）

- **要做什麼**：列出每門課的內部出席人數。
- **怎麼操作**：打開出席人數表。
- **應該看到**：6 門課，`C01` 是 3 人，`C04`、`C05`、`C06` 是 0 人。

## [ ] 6. 登記出席（S5）

- **要做什麼**：登記尚未登記的出席紀錄。
- **怎麼操作**：將 `C06` 的 `E01` 登記為出席；再把同一筆登記為未出席。
- **應該看到**：第一次成功，`C06` 出席人數變成 1；第二次顯示「這筆已經登記過」，內容不變。

## [ ] 7. 錯誤處理

- **要做什麼**：輸入錯誤或連線失敗時顯示中文訊息，程式不會當掉。
- **怎麼操作**：查詢不存在的課程 `C99`；把 `.env` 的密碼改錯後重新開啟，測完改回來。
- **應該看到**：顯示「查無此課程」；連線錯誤時顯示「無法連線資料庫」，視窗不會直接消失。
