# PRD：IT 設備規格小工具（範例成品）

> 這是範例。你請 AI 產生的內容會略有不同，只要涵蓋相同的故事和驗收條件即可。

## 1. 要解決的問題

資訊人員用 Excel 管理設備，每多一種設備就多幾欄，查規格時要在一堆空白欄位裡找。這個工具讓使用者依規格查詢設備，並登記升級和新設備。

**使用者**：一位資訊或總務人員。

## 2. 這次不做的事

- 不做帳號登入和權限管理
- 不做網站或多人同時使用
- 不做設備借還與報修
- 不做折舊計算

## 3. 功能

| 功能 | 故事 | 使用的 SQL（`我的查詢.sql`） |
|---|:---:|---|
| 找高規格筆電 | S1 | 依記憶體查詢筆電 |
| 投影機清單 | S2 | 列出亮度和解析度 |
| 雙面印表機 | S3 | 查詢支援雙面列印的印表機 |
| 升級記憶體 | S4 | 修改一台筆電的記憶體 |
| 新增設備 | S5 | 新增任何類型的設備 |

## 4. 驗收條件

以下數字以你在步驟 2 親手建立 `devices` 資料表並執行步驟 3「AI 產生資料交易檔」後的 16 台初始設備為準（筆電 8、投影機 4、印表機 4，總金額 466,000）。若測試時把資料改亂，在 DBeaver 執行 `TRUNCATE TABLE devices;` 後重新執行步驟 3 產生的交易檔即可恢復。

### 找高規格筆電（S1）
- 我輸入 16，應該看到 **5 台**筆電，第一台是 Dell XPS 15，記憶體 32。

### 投影機清單（S2）
- 我打開清單，應該看到 **4 台**投影機，第一台是 Epson EB-L200F，亮度 4500。

### 雙面印表機（S3）
- 我打開清單，應該看到 **3 台**印表機，沒有 Canon LBP6030。

### 升級記憶體（S4）
- 我把 NB-003 改成 16，再查 16GB 以上的筆電，應該變成 **6 台**。
- NB-003 的 CPU 和螢幕不變。

### 新增設備（S5）
- 我新增平板 TB-001，規格填作業系統和儲存空間，清單應該多一台，共 **17 台**。
- 我用已存在的編號新增，應該看到「設備編號已存在」。

## 5. 使用的資料

| 欄位 | 意思 | 用在 |
|---|---|---|
| `device_id`、`name`、`device_type` | 編號、品名、類型 | 全部功能 |
| `purchase_date`、`price`、`department` | 購入日、單價、部門 | 新增 |
| `specs` | 各類型設備不同的規格 | 全部功能 |
