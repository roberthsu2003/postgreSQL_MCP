# 實戰專案 2｜IT 設備規格表：每一列的欄位都不一樣

> 💻 Excel + DBeaver + AI 工具（資料庫：`devices`）｜ 🎯 學完你會：判斷什麼資料適合 JSONB，並用 SQL 查詢和修改規格

## 這個專案要解決的問題

資訊人員阿哲用 [`設備規格表.xlsx`](./設備規格表.xlsx) 管理公司設備。筆電要記 CPU 和記憶體，投影機要記亮度，印表機要記列印速度。每多一種設備就多幾欄，表越來越寬，大部分格子都是空白。
