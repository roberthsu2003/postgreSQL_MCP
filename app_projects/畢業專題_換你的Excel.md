# 畢業專題｜換你的 Excel：把自己的工作做成小工具

> 💻 你的 Excel + DBeaver + AI 工具 ｜ 🎯 完成後你會有：一個自己設計的資料庫，以及一個工作上用得到的個人 App

[← 回實戰專案大綱](./實戰專案大綱.md)

五個專案練的都是老師準備的 Excel，這次換成你每天在用的那一份。流程完全相同，卡住時可以回到相似的專案對照。

## 開始之前

- [ ] 至少做完[專案 1](./excel1_supplies/) 和[專案 2](./excel2_attendance/) 的步驟 1～4
- [ ] 選一份符合下面條件的 Excel

| 好的題目 | 先不要選 |
|---|---|
| 每週或每月都要更新 | 用一次就不再用的表 |
| 有重複填寫的資料 | 大量合併儲存格、版面複雜的報表 |
| 常常要篩選、加總、核對 | 需要多人同時編輯的表 |

> [!CAUTION]
> **公司資料給 AI 前一定要脫敏。** 真實姓名、電話、身分證、金額都要換掉，或只給 AI 標題列和 10～20 筆假資料。不確定能不能給，就先問主管。

## 步驟 1｜寫 3～5 則 user story

在 Excel 新增一張「需求」工作表：

> 身為 **誰**，我想要 **做什麼**，這樣才能 **得到什麼好處**。

每則都要有驗收條件，例如：「輸入客戶名稱，列出近三個月的訂單，日期由新到舊。」

## 步驟 2｜檢查 Excel，決定拆法

用四個問題檢查：

| 問題 | 問自己 |
|---|---|
| **重複** | 同樣的內容填了很多次嗎？ |
| **修改** | 改一件事要改很多列嗎？ |
| **刪除** | 刪掉一列會失去別的資料嗎？ |
| **新增** | 想新增時，被迫留下一堆空白嗎？ |

接著決定：

- 要拆成哪幾張表，每張表的主鍵是什麼
- 哪些欄位可以空白、有哪些規則
- 有沒有要保留「當時的值」的資料，例如成交單價

## 步驟 3｜親手寫 DDL

在 DBeaver 建立新的資料庫和資料表。**這一步請自己寫**，這是整個專題最重要的練習。

寫完後準備 3～5 列故意有問題的資料，確認資料庫真的會擋下來。

## 步驟 4｜讓 AI 處理資料

依資料量選一種做法：

| 資料量 | 做法 | 參考 |
|---|---|---|
| 幾十筆，已脫敏 | AI 轉成 INSERT 交易檔 | [專案 3 步驟 3](./excel3_expense/3_AI產生資料交易檔.md) |
| 幾百筆以上，或每月更新 | CSV 匯入暫存表，AI 只看樣本寫匯入腳本 | [專案 5 步驟 3](./excel5_stores/3_AI產生匯入腳本.md) |

**幾十筆時的提示詞：**

```text
你是 PostgreSQL 教學助教。我附上一份已脫敏的 Excel。

這是我親手建立的資料表，請嚴格依照它的表名和欄位名稱，不要新增或更改：
（貼上你的 CREATE TABLE）

轉換之前，請先檢查同一筆資料的內容是否前後不一致，有的話列出來問我如何處理。

請產生一份資料交易檔：
1. 只能有 BEGIN;、INSERT、SELECT setval(...) 和 COMMIT;，不要 CREATE、DROP、ALTER 或 TRUNCATE。
2. 依外來鍵順序寫入，先父表，後子表。
3. 如果手動指定了 SERIAL 編號，請用 setval 設定自動編號。
4. 所有資料都要轉換，不可省略，也不可修改內容。

請直接輸出 SQL 程式碼，我會自己在 DBeaver 檢查後執行。
```

執行前先確認：有 `BEGIN` 和 `COMMIT`、沒有 `DROP`、寫入順序正確。

## 步驟 5｜和 Excel 對帳

至少核對這三項，全部相同才算成功：

| 項目 | Excel | SQL |
|---|---|---|
| 筆數 | `COUNTA` | `COUNT(*)` |
| 金額或數量的合計 | `SUM` | `SUM(欄位)` |
| 一個重要的條件統計 | `COUNTIF` 或 `SUMIF` | 加上 `WHERE` 的 `COUNT` 或 `SUM` |

## 步驟 6｜親手寫 DML，完成每則故事

每完成一則故事，就把 SQL 存進 `我的查詢.sql`，並對照驗收條件。寫不出來時，先請 AI 給提示，不要直接要答案。

## 步驟 7｜PRD 和 todolist

1. 建立唯讀帳號：帳號在專案 1 建過的話，只要在新的資料庫執行 `GRANT`。寫法可參考[專案 2 的授權腳本](./excel2_attendance/prompts/00_建立唯讀帳號.sql)，把資料庫名稱換成你的。
2. 依[專案 1 的 PRD 提示詞](./excel1_supplies/prompts/01_MCP讀結構產生PRD.md)，把資料庫和故事換成你的。
3. 依 [todolist 提示詞](./excel1_supplies/prompts/02_PRD產生todolist.md)拆成待辦清單。

## 步驟 8｜做出 App，一項一項驗收

AI 一次做一項，你實際操作，和 todolist 的「應該看到什麼」比對。通過了才往下做。

## ✅ 畢業驗收

- [ ] 資料表是我自己設計、親手建立的
- [ ] 我能說明每張表的主鍵，以及為什麼這樣拆
- [ ] 匯入後和 Excel 對帳相符
- [ ] 每則故事都有我看得懂的 SQL
- [ ] App 的 todolist 每一項都親自驗收過
- [ ] 給 AI 的資料都已經脫敏
