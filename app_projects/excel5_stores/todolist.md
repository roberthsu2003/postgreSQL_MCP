# todolist：門市月報小工具（範例成品）

> 一次只做一項，親自驗收通過才打勾。開始前，先在 DBeaver 執行 `store_full.sql` 恢復第一季資料。

## [ ] 1. 打開視窗，確認連得上資料庫

- **要做什麼**：做出主視窗，連線資料庫並顯示狀態。
- **怎麼操作**：執行 `python app.py`。
- **應該看到**：視窗顯示「已連線，490 張訂單、5 家門市」。

## [ ] 2. 各門市月營收（S1）

- **要做什麼**：顯示各門市每月的已完成營業額。
- **怎麼操作**：打開月營收報表。
- **應該看到**：15 列，第一列是台中逢甲店 2024-01、6,205，下方合計 80,985。

## [ ] 3. 熱銷排行（S2）

- **要做什麼**：顯示銷售數量前 5 名的商品。
- **怎麼操作**：打開熱銷排行。
- **應該看到**：5 項商品，第一名翡翠檸檬綠 78 個，第二名焦糖瑪奇朵 65 個。

## [ ] 4. 忠誠會員名單（S3）

- **要做什麼**：列出每個月都有消費的會員。
- **怎麼操作**：打開忠誠會員名單。
- **應該看到**：24 位會員，第一位謝哲瑋（0963-728-214）2,530；另一位謝哲瑋（0943-645-351）也在名單上。

## [ ] 5. 績優店員（S4）

- **要做什麼**：列出業績高於平均的店員。
- **怎麼操作**：打開績優店員名單。
- **應該看到**：6 位店員，第一位郭俊宏（高雄巨蛋店）9,525。

## [ ] 6. 匯入每月 CSV（S5）

- **要做什麼**：選擇 CSV 檔，放進暫存表後執行匯入，並顯示結果。
- **怎麼操作**：選擇 `門市銷售明細_202404.csv` 匯入；再匯入同一個檔案一次。
- **應該看到**：第一次顯示「讀取 7 筆，新增 5 張訂單」，訂單總數 495，四月出現在月營收報表；第二次顯示「新增 0 張訂單」，訂單總數仍是 495。

## [ ] 7. 錯誤處理

- **要做什麼**：檔案錯誤或連線失敗時顯示中文訊息，程式不會當掉。
- **怎麼操作**：匯入一個欄位不對的 CSV；把 `.env` 的密碼改錯後重新開啟，測完改回來。
- **應該看到**：匯入錯誤時顯示「檔案格式不正確」，訂單總數不變；連線錯誤時顯示「無法連線資料庫」，視窗不會直接消失。
