# 實戰專案 4｜差旅報銷單：一張工作表拆成四張表

> 💻 Excel + DBeaver + AI 工具（資料庫：`expense`）｜ 🎯 學完你會：設計多張關聯的表、處理自動編號，並用多表 JOIN 完成報銷流程

[← 回第 5 章實戰專案](../README.md)

## 這個專案要解決的問題

會計小雯每個月彙整 [`差旅報銷單.xlsx`](./差旅報銷單.xlsx)。部門、主管和費用類別重複填寫，同一張發票可能被報兩次，出納也搞不清楚哪些單據該撥款。

這個專案要把它拆成部門、費用類別、員工、報銷單四張表，做出一個能跑完審核流程的工具。
